# Demystifying LLM-as-a-Judge: Analytically Tractable Model for Inference-Time Scaling

Indranil Halder Affiliation: John A. Paulson School of Engineering And
Applied Sciences, Harvard University Correspondence to:
<ihalder@g.harvard.edu>    Cengiz Pehlevan Affiliation: John A. Paulson

###### Abstract

Recent developments in large language models have shown advantages in
reallocating a notable share of computational resource from training
time to inference time. However, the principles behind inference time
scaling are not well understood. In this paper, we introduce an
analytically tractable model of inference-time scaling: Bayesian linear
regression with a reward-weighted sampler, where the reward is
determined from a linear model, modeling LLM-as-a-judge scenario. We
study this problem in the high-dimensional regime, where the
deterministic equivalents dictate a closed-form expression for the
posterior predictive mean and variance. We analyze the generalization
error when training data are sampled from a teacher model. We draw $`k`$
inference-time samples and select via softmax at a temperature applied
to a quadratic reward. When the reward is not too different from the
teacher, the generalization error decreases monotonically with
increasing inference time samples $`k`$. However, the specific reward
that optimizes inference-time selection generally differs from the
teacher. In contrast, substantial reward misspecification induces a
finite optimal $`k`$ beyond which more sampling can increase the
generalization error. For fixed $`k`$, there exists an optimal sampling
temperature. We experimentally verify these facts in large language
model inference with an additional large language model as a judge. In
the “best-of-$`k`$” limit with the teacher as reward, we theoretically
show that the generalization error decays as $`\Theta(1/k^{2})`$ and
determine the leading coefficient via extreme value theory. These
formulas delineate domains where scaling inference-time computation is
provably preferable to collecting more data. Finally, we demonstrate
that when task difficulty increases, the previously mentioned advantage
of inference-time compute degrades.

Machine Learning, ICML

## 1 Introduction

Scaling training compute via larger models and more data drives dramatic
gains (Hestness et al., 2017; Kaplan et al., 2020; Hoffmann et al.,
2022). In parallel, across tasks, allowing models to ‘think longer’ at
inference by sampling multiple candidates, re-ranking with a reward, or
aggregating votes consistently improves precision and reliability (Wang
et al., 2023; Zheng et al., 2023; Zhang et al., 2024; Wu et al., 2024;
Snell et al., 2025). Best-of-$`k`$ (choose the highest-reward sample
based on the feedback of a judge large language model) and majority
voting (choose the consensus among the generated answers) have become
standard inference-time tools (Brown et al., 2024; Schaeffer et al.,
2025a; Chen et al., 2024a; Huang et al., 2025a) along with
self-verification (Saunders et al., 2022; Weng et al., 2023).

Despite widespread adoption, key questions for inference-time
computation lack crisp answers. How to optimally configure
inference-time sampling to minimize generalization error under realistic
compute constraints and how to allocate compute optimally between
pretraining and inference time remain open questions (Wu et al., 2024).
Which reward model should we use for inference? What is the appropriate
inference-time sampler, e.g., temperature settings? How large should
$`k`$ be and when do more samples stop helping? How should we allocate a
fixed compute budget between training and inference to minimize
generalization error? We lack a simple, solvable model that gives us
intuitions and actionable prescriptions.

To fill this gap, we propose a minimal and analytically tractable
setting: Bayesian regression based on a teacher-student setting with a
controlled reward and a temperature-dependent inference-time sampler, in
which best-of-$`k`$ appears as limit. This setup is a proxy for
LLM-as-a-judge providing reward for the generated answers from a
base-LLM. We theoretically study the generalization error $`\delta`$ as
a function of the size of the training data set $`n`$, the dimension of
the data $`d`$, the number of inference time samples $`k`$, the sampling
temperature $`T`$ and the reward parameter $`\mathbf{w}_{R}`$ and
demonstrate various optimality conditions on these parameters. We
generalize these theoretical discussion to generic probabilistic models
in Appendix F.

This simple model recapitulates existing findings on large language
model (LLM) inference and yields novel predictions that we evaluate in
this paper. It reproduces the empirical observation that unbounded
increases in the number of inference-time samples do not confer
additional benefit (Snell et al., 2025). Furthermore, it predicts the
existence of an optimal temperature for the reward process. Further,
strong rewards shift optimal temperature to a lower value. We
empirically examine and confirm this prediction using
Llama-3-8B-Instruct, DeepSeek-R1-Distill-Qwen-1.5B etc.

At the technical level our contributions are the following:

- •
  We propose a solvable model for inference-time scaling: Bayesian
  regression where the ground truth is given by the teacher model
  $`y=\mathbf{w}_{T}\cdot\mathbf{x}/\sqrt{d}`$ and the reward function
  is quadratic
  $`r(y,\mathbf{x})=-(y-\mathbf{w}_{R}\cdot\mathbf{x}/\sqrt{d})^{2}`$.
  We generate $`k`$ samples at inference and choose using a softmax at
  temperature $`T`$ over the reward. This method is conceptually close
  to (Aminian et al., 2025; Faria and Smith, 2025). We present a formula
  for the generalization error $`\delta`$ in the proportional limit:
  $`d\to\infty,n\to\infty`$ with $`\alpha=d/n`$ fixed.
- •
  In order to derive analytic insights about the inference time
  optimization, we derive a series expansion for $`\delta`$ around large
  $`T`$, making explicit its dependence on $`n`$, $`k`$, and the
  alignment between $`\mathbf{w}_{R}`$ and $`\mathbf{w}_{T}`$. The
  analytical expansion shows a sharp dependence on reward quality: when
  $`\mathbf{w}_{R}`$ is sufficiently close to $`\mathbf{w}_{T}`$, i.e.,
  small $`\|\mathbf{w}_{R}-\mathbf{w}_{T}\|/\|\mathbf{w}_{T}\|`$,
  increasing $`k`$ monotonically decreases $`\delta`$ (see Figure 1),
  and the reward $`\mathbf{w}_{R}`$ that optimizes inference-time
  selection generally _differs_ from the data-generating teacher
  $`\mathbf{w}_{T}`$ (Remark 2, Figure 3). In contrast, when
  $`\mathbf{w}_{R}`$ is poorly aligned, $`\delta`$ is non-monotone in
  $`k`$, yielding an _optimal_ finite $`k`$ (Remark 3, Figure 4, 7(a)),
  echoing phenomena observed empirically in large language models (Snell
  et al., 2025). Furthermore we show that at fixed $`k`$, there exists
  an _optimal_ temperature $`T`$ for the rewarding process (Remark 4,
  Figure 5, 7(b)). A similar yet distinct observation has been made in
  large language models (Du et al., 2025) for sampling temperature of
  the model itself. We emphasize that our result is about the sampling
  temperature of the rewarding process - different from the sampling
  temperature of the language model. In Appendix F, we discussion
  statistical origin of these results for a generic probabilistic model
  with a general reward.
- •
  To explore the best-of-k case, we consider the $`T=0`$ limit. Using
  extreme value theory, we analytically prove that the expectation value
  of $`\delta`$ scales as $`\Theta(k^{-2})`$ at large $`k`$ when we have
  access to the teacher, i.e, $`\mathbf{w}_{R}=\mathbf{w}_{T}`$ (Remark
  5, Figure 6, 9). In Appendix F, we show that in general depending on
  the coverage coefficient $`\beta`$ of the predictive distribution near
  the target one can get more general scaling law
  $`\Theta(k^{-\frac{2}{1+\beta}})`$ that fits the plot Figure 9 in
  large language models. Further, based on our theoretical analysis in
  best-of-$`k`$ limit, we quantify the parametric region where scaling
  inference-time compute is more beneficial compared to training
  compute. Finally we note that when task difficulty increases, the
  previously mentioned advantage of inference-time compute degrades.
- •
  To test our predictions in realistic settings, we have generated
  inference time samples from Llama-3-8B-Instruct and
  DeepSeek-R1-Distill-Qwen-1.5B on openai/gsm8k validation dataset (see
  Appendix H.2 for the details and more empirical results). For each
  question and response pair we used Mistral-7B-Instruct-v0.3 or
  Qwen2.5-Math-PRM-7B to generate a reward score. Finally, we observed
  the existence of an optimal $`k,T`$ similar to the theoretical
  predictions above (see Figure  7 and  8). In particular for the
  best-of-$`k`$ strategy, Figure  9 shows scaling laws similar to the
  one observed in theoretical analysis for a nearly ideal reward model.

Now we turn to survey the ideas in the literature related to our work.

### Related Works

##### Method of deterministic equivalence.

In the context of linear regression (Krogh and Hertz, 1992; Dicker,
2016; Dobriban and Wager, 2018; Nakkiran, 2019; Advani et al., 2020;
Hastie et al., 2022), kernel regression (Sollich, 1998; Sollich and
Halees, 2002; Bordelon et al., 2020; Canatar et al., 2021; Spigler
et al., 2020; Simon et al., 2021; Loureiro et al., 2021), and random
feature models (Hastie et al., 2022; Louart et al., 2018; Mei and
Montanari, 2022; Adlam and Pennington, 2020; d’Ascoli et al., 2020;
d’Ascoli et al., 2020; Loureiro et al., 2021; Bahri et al., 2022;
Zavatone-Veth and Pehlevan, 2023a; Dhifallah and Lu, 2020; Hu and Lu,
2022; Maloney et al., 2022; Bach, 2024) method of deterministic
equivalence (Voiculescu et al., 1992; Zee, 1996) has been used
extensively for discussions of higher dimensional statistics
(Misiakiewicz and Saeed, 2024; Atanasov et al., 2024). These ideas have
been used to discuss training time scaling laws in simple models
(Spigler et al., 2020; Bordelon et al., 2020; Bahri et al., 2022;
Maloney et al., 2022; Simon et al., 2021; Bordelon et al., 2024;
Zavatone-Veth and Pehlevan, 2023b; Paquette et al., 2024; Lin et al.,
2024; Bordelon et al., 2025). We use this technique to simplify the
posterior probability distribution of the Bayesian regression model.

##### Inference-time scaling.

A growing body of work investigates how to allocate and exploit
inference-time compute to improve predictive performance, with empirical
gains reported across tasks and domains based on majority voting  (Chen
et al., 2024a; Snell et al., 2025; Setlur et al., 2025; Arora and
Zanette, 2025; Wu et al., 2024; Liu et al., 2025; Du et al., 2025; Huang
et al., 2025a) or a best-of-$`k`$ strategy  (Wang et al., 2023; Yao
et al., 2023a; Brown et al., 2024; Levi, 2024; Schaeffer et al., 2025b;
Huang et al., 2025b; Chen et al., 2024b; Du et al., 2025; Chen et al.,
2025; Aminian et al., 2025; Faria and Smith, 2025; Khalaf et al., 2026).
These procedures are often paired with reasoning-oriented prompting and
structured search that expand the candidate set before selection (Wei
et al., 2022; Yao et al., 2023b; Wu et al., 2024). Recent work has also
begun to compare different inference-time scaling paradigms
theoretically. For majority-vote-style compound systems, Chen et al.
(2024a) develop a theoretical model for classification problems and
analyze when repeated calls to a language model improve accuracy.
Relatedly, Huang et al. (2025c) provide a theoretical account of
self-consistency-based selection and compare its sample complexity with
other test-time scaling procedures. In another direction, Di et al.
(2025) propose a method that combines ideas from majority voting and
best-of-$`k`$: the algorithm first uses frequency information to
restrict attention to plausible candidate answers and then applies
reward-based selection within this filtered set. This perspective
highlights an important limitation of pure best-of-$`k`$ selection: when
the reward model is imperfect, aggressively selecting the highest-reward
sample can amplify reward misspecification. The use of consensus or
frequency information can therefore act as a stabilizing mechanism. More
close to our work is the scaling law of (Brown et al., 2024; Schaeffer
et al., 2025b) for best-of-$`k`$ strategy. For a given trained model,
both these works explain pass@k performance for correctness of the
prediction. We study similar questions with imperfect reward and discuss
best-of-$`k`$ (and more generally softmax weighted selection)
generalization error when reasoning is taken into account both
theoretically and empirically.

## 2 Problem Setup: Bayesian Regression With Reward-weighted Sampling

We start by introducing our solvable model.

### 2.1 Training Method - Prior and Posterior Distribution

We study a supervised regression setting with a linear teacher model
that maps inputs to outputs and then adds observation noise. Throughout,
let $`\mathbf{x}\in\mathbb{R}^{d}`$ denote an input vector drawn from a
zero-mean Gaussian with covariance $`\bm{\Sigma}`$, written
$`\mathbf{x}\sim\mathcal{N}(0,\bm{\Sigma})`$. We assume
$`\text{Tr}(\bm{\Sigma})=\Theta_{d}(d)`$ so that the total feature
variance scales linearly with dimension; a canonical case is
$`\bm{\Sigma}=\mathbf{I}`$. The teacher parameter $`\mathbf{w}_{T}`$ is
taken to have norm $`\|\mathbf{w}_{T}\|^{2}=d`$, and the output is given
by:

```math
\displaystyle y=\mathbf{w}_{T}\cdot\frac{\mathbf{x}}{\sqrt{d}}+\eta,\quad\eta\sim\mathcal{N}(0,\sigma^{2}). \tag{1}
```

Given a training set
$`\mathcal{D}=\left\{(\mathbf{x}^{i},y^{i})_{i=1}^{n}\right\}`$ sampled
i.i.d. from the teacher, we adopt a Bayesian linear regression
perspective with an isotropic Gaussian prior on the weights,
$`\mathcal{N}(0,\gamma^{2}\mathbf{I})`$. Bayes’ rule yields the
posterior distribution over weights:

```math
\displaystyle p(\mathbf{w}|\mathcal{D})=\frac{p(\mathcal{D}|\mathbf{w})p(\mathbf{w})}{p(\mathcal{D})}. \tag{2}
```

Predictions for a new test input $`\mathbf{x}`$ are obtained by
marginalizing the likelihood under this posterior, producing the
_posterior predictive_ distribution:

```math
\displaystyle p(y|\mathbf{x},\mathcal{D})=\int d\mathbf{w}\,p(\mathbf{w}|\mathcal{D})p(y|\mathbf{x},\mathbf{w}). \tag{3}
```

Next we state the standard result that makes predictive distribution
explicit.

###### Remark 1.

Analytical formula for the posterior predictive is given by

```math
\displaystyle\hskip 25.6073ptp(y|\mathbf{x},\mathcal{D})=\mathcal{N}\left(\bm{\mu}\cdot\frac{\mathbf{x}}{\sqrt{d}},\frac{\mathbf{x}}{\sqrt{d}}^{\top}\bm{\Omega}\frac{\mathbf{x}}{\sqrt{d}}+\sigma^{2}\right) \tag{4}
```

```math
\displaystyle\bm{\mu}=\frac{1}{\sigma^{2}}\bm{\Omega}\sum_{i=1}^{n}y^{i}\frac{\mathbf{x}^{i}}{\sqrt{d}},\quad\bm{\Omega}^{-1}=\frac{1}{\sigma^{2}}\sum_{i=1}^{n}\frac{\mathbf{x}^{i}}{\sqrt{d}}{\frac{\mathbf{x}^{i}}{\sqrt{d}}}^{\top}+\frac{1}{\gamma^{2}}\mathbf{I} \tag{5}
```

###### Proof-sketch.

This is a standard result (Bishop, 2013).

### 2.2 Inference-time Sampling And The Reward Model

Suppose that we have a reward model that evaluates our predictions,
$`r(y,\mathbf{x})`$. We will use this to generate an output with the
following procedure:

0:  input $`\mathbf{x}`$, posterior predictive
$`p(y\mid\mathbf{x},\mathcal{D})`$, reward $`r`$, temperature $`T`$,
number of samples $`k`$

1:  for $`i\leftarrow 1`$ to $`k`$ do

2:   sample $`y_{i}\sim p(y\mid\mathbf{x},\mathcal{D})`$

3:   $`l_{i}\leftarrow\exp\!\big(r(y_{i},\mathbf{x})/T\big)`$

4:  end for

5:  $`q_{i}\leftarrow l_{i}/\sum_{j=1}^{k}l_{j}\quad(i=1,\ldots,k)`$

6:  Draw $`I\sim\mathrm{Categorical}(q_{1},\ldots,q_{k})`$

7:  return $`y_{\mathrm{out}}\leftarrow y_{I}`$

Reward-Weighted Sampling

For simplicity, we will assume a reward given by

```math
\displaystyle r(y,\mathbf{x})=-\left(y-\mathbf{w}_{R}\cdot\frac{\mathbf{x}}{\sqrt{d}}\right)^{2}. \tag{6}
```

Note that $`\mathbf{w}_{R}\neq\mathbf{w}_{T}`$ in general. In realistic
settings, this models the fact that LLM-as-a-Judge is not a perfect
verifier. Hence, this settings will allow us to study the effect of the
quality of the Judge on generalization error.

In this paper, we are interested in computing the generalization error
of this model defined by

```math
\displaystyle\delta=\mathbb{E}_{\mathbf{x}}(\delta(\mathbf{x})), \tag{7}
```

```math
\displaystyle\delta(\mathbf{x})=\mathbb{E}_{y_{1},\dots,y_{k}}\left[\frac{\sum_{i=1}^{k}\big(y_{i}-\mu_{T}(\mathbf{x})\big)^{2}\,e^{-\big(y_{i}-\mu_{R}(\mathbf{x})\big)^{2}/T}}{\sum_{j=1}^{k}e^{-\big(y_{j}-\mu_{R}(\mathbf{x})\big)^{2}/T}}\right]. \tag{8}
```

Here we use the notation
$`\mu_{T}(\mathbf{x}):=\mathbf{w}_{T}\cdot\frac{\mathbf{x}}{\sqrt{d}}`$,
$`\mu_{R}(\mathbf{x}):=\mathbf{w}_{R}\cdot\frac{\mathbf{x}}{\sqrt{d}}`$.

## 3 Analysis Of The Generalization Error

In this section we analyze the high-dimensional behavior of the Bayesian
regression model introduced above, with a particular focus on how
inference-time sampling and the reward model shape the error.

Before we get into the details of further theoretical analysis, we
summarize the empirical findings in Figure  2 and compare with results
of Result 1:

- •
  When the reward is sufficiently accurate—formally, when
  $`\|\mathbf{w}_{R}-\mathbf{w}_{T}\|/\|\mathbf{w}_{T}\|`$ is small—the
  generalization error $`\delta`$ decreases _monotonically_ with the
  number of inference-time samples $`k`$. We denote by $`\mathcal{R}`$
  (highlighted in red in Figure 1) the region of reward weights
  exhibiting this monotonic behavior. Notably, within $`\mathcal{R}`$
  the teacher reward is _not_ optimal for fixed $`(k,T)`$; i.e.,
  $`\mathbf{w}_{R}=\mathbf{w}_{T}`$ does not minimize $`\delta`$ (see
  Figure 2(a)).
- •
  Comparing figures  2(a)–2(b), we note that the set $`\mathcal{R}`$
  shrinks as the temperature $`T`$ decreases (see also Figure 1).
  Outside this set, in its complement $`\mathcal{R}^{\complement}`$
  (blue in Figure 1), Figure 2 shows that $`\delta`$ becomes
  _non-monotonic_ in $`k`$, with a finite $`k`$ beyond which increasing
  $`k`$ worsens error. Consequently, for a fixed $`\mathbf{w}_{R}`$,
  lowering $`T`$ can induce a transition from $`\mathcal{R}`$ to
  $`\mathcal{R}^{\complement}`$; equivalently, at fixed $`k`$ there may
  exist an _optimal_ temperature $`T`$ that minimizes $`\delta`$
  (confirmed in Figure 5).

In the high dimensional setting, deterministic-equivalents simplify the
predictive mean and variance by $`m`$ and $`\Sigma=s^{2}`$ as follows:

###### Result 1.

In the limit of $`d,n\to\infty`$, with $`\alpha=d/n<1`$ fixed, for
sufficiently small noise scale, i.e., there exists
$`\sigma_{c}(\alpha,R)`$ (see Appendix B for an explicit expression)
such that for $`\sigma\ll\sigma_{c}(\alpha,R)`$, the generalization
error is given by

```math
\displaystyle\delta(\mathbf{x})=\mathbb{E}\left[\frac{\sum_{i=1}^{k}\big(y_{i}-\mu_{T}(\mathbf{x})\big)^{2}\,e^{-\big(y_{i}-\mu_{R}(\mathbf{x})\big)^{2}/T}}{\sum_{j=1}^{k}e^{-\big(y_{j}-\mu_{R}(\mathbf{x})\big)^{2}/T}}\right], \tag{9}
```

to the leading order in $`\sigma`$. Here the expectation is over
$`y_{i}\sim\mathcal{N}(m(\mathbf{x}),s(\mathbf{x})^{2}),i=1,2,\dots,k`$.
The posterior predictive has a mean $`m(\mathbf{x})`$ and variance
$`\Sigma(\mathbf{x})=s(\mathbf{x})^{2}`$ as follows

```math
\displaystyle m(\mathbf{x})=\frac{\mathbf{x}}{\sqrt{d}}^{\top}\mathbf{A}_{R}\mathbf{w}_{T},\,\,s(\mathbf{x})^{2}=\sigma^{2}+\gamma^{2}\,\frac{\mathbf{x}}{\sqrt{d}}^{\top}\mathbf{B}_{R}\,\frac{\mathbf{x}}{\sqrt{d}}. \tag{10}
```

The matrices $`\mathbf{A}_{R},\mathbf{B}_{R}`$ are defined in terms of
renormalized ridge $`R`$ that satisfies

```math
R\Big(1-\alpha\,m_{\bm{\Sigma}}(R)\Big)=\hat{R}:=\frac{\sigma^{2}}{\gamma^{2}}\alpha,\,\,m_{\bm{\Sigma}}(R):=\frac{1}{d}\text{Tr}\!\big[\bm{\Sigma}(\bm{\Sigma}+RI)^{-1}\big]. \tag{11}
```

The solution of $`R`$ from above equation is used to define
$`\mathbf{A}_{R},\mathbf{B}_{R}`$ as follows

```math
\mathbf{A}_{R}:=\bm{\Sigma}(\bm{\Sigma}+R\mathbf{I})^{-1},\,\,\mathbf{B}_{R}:=R(\bm{\Sigma}+R\mathbf{I})^{-1}=\mathbf{I}-\mathbf{A}_{R}. \tag{12}
```

###### Proof-sketch.

See appendix B for more details.

In this paper we will focus on the simple setup where
$`\bm{\Sigma}=S^{2}\mathbf{I}`$. In this case we can explicitly solve
for the renormalized ridge as follows

```math
\displaystyle R=\frac{1}{2}S^{2}\left(\frac{d}{n}+\frac{\hat{R}}{S^{2}}-1+\left(\left(1-\frac{d}{n}-\frac{\hat{R}}{S^{2}}\right)^{2}+\frac{4\hat{R}}{S^{2}}\right)^{\frac{1}{2}}\right). \tag{13}
```

In addition in this case the matrices $`\mathbf{A}_{R},\mathbf{B}_{R}`$
are proportional to identity matrix

```math
\mathbf{A}_{R}:=\frac{S^{2}}{R+S^{2}}\mathbf{I},\qquad\mathbf{B}_{R}:=\frac{R}{R+S^{2}}\mathbf{I}. \tag{14}
```

These expressions are going to be useful in the later sections to have
close form expression of generalization error $`\delta`$ in various
parameter domains of interest.

### 3.2 High- And Low-temperature Behavior Of The Generalization Error

We now provide a theoretical account of these phenomena. In this
section, we present two results that will help us gain insight later
into generalization error behavior. Specifically, we analyze $`\delta`$
in two complementary regimes of the reward temperature: (i) a
high-temperature (weak-reward) expansion, where the selection
reweighting is perturbative, and (ii) a low-temperature
(“best-of-$`k`$”) regime, where selection concentrates on high-reward
samples and extreme-value effects dominate. The next two results
formalize these regimes.

In the limit of an ample amount of data $`d/n\to 0`$ with a flat prior
$`\sigma/\gamma\to 0`$, the temperature scale is controlled by
$`s^{2}\approx\sigma^{2}`$. In the high-temperature limit we present the
following result.

###### Result 2 (High-$`T`$ expansion).

For temperature much larger that the posterior predictive’s variance,
i.e., $`T\gg s(\mathbf{x})^{2}`$ the expectation value of the error can
be organized as a series as follows

```math
\displaystyle\delta(\mathbf{x}) \displaystyle=\Delta_{T}(\mathbf{x})^{2}+s^{2}(\mathbf{x}) \tag{15}
```

```math
\displaystyle+\Sigma_{l=1}^{3}(-1)^{l}\frac{C_{l}(\mathbf{x})}{t(\mathbf{x})^{l}}\prod_{i=1}^{l}\Big(1-\tfrac{i}{k}\Big)+\mathcal{O}\!\Big(t(\mathbf{x})^{-4}\Big)
```

Where we have defined $`t(\mathbf{x})=\frac{T}{2s(\mathbf{x})^{2}}`$ and

```math
\displaystyle C_{l}(\mathbf{x})=2\,\Delta_{T}(\mathbf{x})\Delta_{R}(\mathbf{x})+s^{2}(\mathbf{x})+(l-1)\Delta_{R}(\mathbf{x})^{2} \tag{16}
```

```math
\displaystyle\Delta_{T}(\mathbf{x}):=m(\mathbf{x})-\mu_{T}(\mathbf{x}),\quad\Delta_{R}(\mathbf{x}):=m(\mathbf{x})-\mu_{R}(\mathbf{x}).
```

All other quantities are as in Result 1.

###### Proof-sketch.

Let $`z`$ denote the partition function over $`k`$ i.i.d. draws from
$`p(y|\mathbf{x},\mathcal{D})`$ with quadratic reward; expand
$`\mathbb{E}\log z`$ around $`\mathbb{E}z`$ via a controlled the
cumulant expansion for $`t\!\gg\!1`$. The $`1/t,1/t^{2}`$ and
$`1/t^{3}`$ terms produce the $`C_{1}(\mathbf{x}),C_{2}(\mathbf{x})`$
and $`C_{3}(\mathbf{x})`$ structure; substituting the deterministic
equivalents for $`m,\Sigma`$ converts it to the form mentioned in the
Result. See Appendix C for the details.

In Appendix F, we show that the structure of the perturbation theory
remains the same for a generic probabilistic model with a general
reward. We also discuss statistical significance of various terms in the
expansion.

Now we turn to best-of-$`k`$ setting, given by the $`T\to 0`$ limit, and
present our theoretical finding below.

###### Result 3 (Low-$`T`$ best-of-$`k`$ sampling).

When we have access to the exact teacher weight
$`\mathbf{w}_{R}=\mathbf{w}_{T}=\mathbf{w}`$, the leading order result
for $`T\to 0`$ followed by $`k\to\infty`$ is given by

```math
\delta(\mathbf{x})\;=\;\frac{\pi}{k^{2}}\ \!\left[s^{2}(\mathbf{x})\ \exp\!\left(\frac{\Delta_{T}(\mathbf{x})^{2}}{s^{2}(\mathbf{x})}\right)\right]\  \tag{17}
```

All the quantities are as in Result 1 and Result 2.

###### Proof-sketch.

At $`T=0`$, the softmax reduces to a minimum of chi-squared random
variables. This is governed by the Weibull distribution at large $`k`$
according to extreme value theory. Finally, substituting the
deterministic equivalents for $`m,\Sigma`$ and evaluating the
expectation value gives the generalization error mentioned in the
Result. See Appendix 11 for details.

Note that the low-temperature scaling of $`\delta`$ with the number of
inference time samples $`k`$ is independent of the amount of the amount
of training data. These theoretical results are compared with the
experiment in Figure 6.

In Appendix F, we establish that in general depending on the coverage
coefficient $`\beta`$ of the predictive distribution near the target one
can get more general scaling law $`\Theta(k^{-\frac{2}{1+\beta}})`$. For
the Gaussian predictive distribution one gets the $`\Theta(k^{-2})`$ law
as in the Result 3.

### 3.3 Optimal Reward May Differ From The Teacher

Naively, one might expect that the optimal reward, one that leads to the
best generalization error, is given by the teacher itself. However,
Figure 3 shows that this may not always be true. Here, we compare the
generalization error achieved when the reward weight equals the teacher
($`\mathbf{w}_{R}=\mathbf{w}_{T}`$) versus when it differs, across
different values of $`k`$ and $`T`$. The plot reveals a consistent
pattern: when $`\mathbf{w}_{R}`$ is close to $`\mathbf{w}_{T}`$, the
error is _lower_ when the reward weight is _slightly shifted_ away from
the teacher. This additional shift required for the optimal reward grows
systematically with the temperature scale $`T`$.

We can get insight into this behavior exploiting our Result 2. By
setting the first derivative of $`\delta(\mathbf{x})`$, given in Result
2, with respect to $`\mathbf{w}_{R}`$ to zero, we arrive at the
following conclusion:

![](arxiv-2512-19905v3--c3117623cda7.figures/figure-5.webp)

Figure 3: In the plot we have chosen
$`S=1,\sigma=10^{-4},\gamma=10^{-3},n=10^{4},d=10`$, $`k=50`$ and used
the following parameterization
$`\mathbf{w}_{R}=(1+cR/(R+S^{2}))\mathbf{w}_{T}`$ and sampled
$`\mathbf{w}_{T}\sim\mathcal{N}(0,2^{2}\mathbf{I})`$. This plot shows
dependence of $`\delta`$ on $`c`$ for various values of $`T`$ at fixed
$`k`$. We see that $`\delta`$ is minimized at
$`c\approx T/(2\sigma^{2})`$ as expected from Remark 2.

###### Remark 2.

There exists an optimal reward weight that differs from the teacher
weight by the following formula

```math
\mathbf{w}_{R}(\mathbf{x})=\mathbf{w}_{T}+\left(\frac{k}{k-2}t(\mathbf{x})\right)\mathbf{B}_{R}\,\mathbf{w}_{T} \tag{18}
```

This formula provides a controlled approximation in the domain stated in
Result 2 as long as

```math
\frac{\|\mathbf{w}_{R}(\mathbf{x})-\mathbf{w}_{T}\|}{\|\mathbf{w}_{T}\|}\ll 1. \tag{19}
```

The Remark also quantifies the empirically observed fact that as $`T`$
increases, the optimal $`\mathbf{w}_{R}`$ moves proportionally away from
$`\mathbf{w}_{T}`$.

### 3.4 There Exists An Optimal Number For Inference-time Samples

Figure 4 shows that when the reward weight $`\mathbf{w}_{R}`$ is
sufficiently misaligned from the teacher $`\mathbf{w}_{T}`$, the test
error as a function of the number of inference samples $`k`$ is
_non-monotonic_: it first decreases (benefiting from a better draw among
$`k`$ candidates) and then _increases_ beyond an optimal value of $`k`$.
We can get some more insight into this behavior by the following Remark.

![](arxiv-2512-19905v3--c3117623cda7.figures/figure-6.webp)

Figure 4: In the plot we have chosen
$`S=1,\sigma=10^{-4},\gamma=10^{-3},n=10^{4},d=10`$, $`T=200\sigma^{2}`$
and used the following parameterization
$`\mathbf{w}_{R}=(1+cR/(R+S^{2}))\mathbf{w}_{T}`$ and sampled
$`\mathbf{w}_{T}\sim\mathcal{N}(0,2^{2}\mathbf{I})`$. We plot the scaled
value of $`\delta-\delta_{\infty},\delta_{\infty}\approx\delta_{k=100}`$
as a function of $`k`$ for various values of $`c`$. This shows existence
of an optimal value of $`k`$ - theoretical prediction for it is denoted
as $`k_{opt}`$ as given in Remark 3.

###### Remark 3.

There exists an optimal value of inference samples $`k`$, when Result 2
is valid and

```math
t<\frac{3C_{2}(\mathbf{x})}{C_{1}(\mathbf{x})}\equiv t_{*},\quad C_{1}(\mathbf{x})>0,\quad C_{2}(\mathbf{x})>0 \tag{20}
```

In this case, as we increase $`k`$ the error decreases until when we
reach

```math
k=\left\lceil\frac{4}{3}\frac{t_{*}}{t_{*}-t}\right\rceil\approx\frac{2t_{*}}{t_{*}-t} \tag{21}
```

and far beyond this, increase in $`k`$ increases the error. For larger
values of $`t`$, increase in $`k`$ always decreases error.

###### Proof-sketch.

This is obtained by setting the first derivative of
$`\delta(\mathbf{x})`$, given in Result 2, with respect to $`k`$ to
zero.

Note that above Remark only applies when $`t\gg 1`$ and
$`t<3C_{2}/C_{1}`$. But when $`\mathbf{w}_{R}`$ is sufficiently close to
$`\mathbf{w}_{T}`$, $`C_{2}/C_{1}\sim 1`$. When $`\mathbf{w}_{R}`$ is
sufficiently close to $`\mathbf{w}_{T}`$, increase in $`k`$ decreases
the error $`\delta`$ since in this case above Remark does not apply.
Whereas when $`\mathbf{w}_{R}`$ is sufficiently far from
$`\mathbf{w}_{T}`$ ($`C_{2}/C_{1}`$ becomes larger since $`\Delta_{R}`$
grows), above Remark shows existence of an optimal value for $`k`$.

### 3.5 There Exists An Optimal Temperature For Reward Sampling

Figure 5 examines generalization $`\delta`$ error as a function of
temperature $`T`$ at fixed number of inference time samples $`k`$.
Empirically, the generalization error exhibits a clear local minimum
around a critical value of $`T`$, rather than decreasing or increasing
monotonically. Interpreting this through the high-$`T`$ expansion, the
minimum corresponds to a particular balance between the first- and
second-order correction terms governed by $`C_{1}`$ and $`C_{2}`$.
Temperature $`T`$ controls how sharply the selection favors high-reward
samples among the $`k`$ candidates. At very high temperatures, selection
is nearly uniform and the benefits of the reward model are muted; at
very low temperatures, selection becomes too aggressive and can
over-amplify any mismatch between $`\mathbf{w}_{R}`$ and
$`\mathbf{w}_{T}`$, increasing error. The optimal temperature thus
trades off these effects. It scales linearly with $`\Sigma`$ and grows
with misspecification via $`C_{2}/C_{1}`$. The location of the optimal
temperature for given $`k,\mathbf{w}_{R}`$ is determined from the
theoretical result below:

![](arxiv-2512-19905v3--c3117623cda7.figures/figure-7.webp)

Figure 5: In the plot we have chosen
$`S=1,\sigma=10^{-4},\gamma=10^{-3},n=10^{4},d=10`$ and used the
following parameterization
$`\mathbf{w}_{R}=(1+cR/(R+S^{2}))\mathbf{w}_{T}`$ and sampled
$`\mathbf{w}_{T}\sim\mathcal{N}(0,2^{2}\mathbf{I})`$. This plot shows
existence of an optimal value of temperature $`T`$ at fixed $`k=50`$.
For the optimal value, we find reasonable agreement with the theoretical
prediction in in Remark 4.

###### Remark 4.

For a given number of inference-time samples $`k>2`$, training dataset
size $`n`$ and reward weight $`\mathbf{w}_{R}`$, there exists an optimal
temperature for the rewarding process

```math
t(\mathbf{x})=2\left(1-\frac{2}{k}\right)\frac{C_{2}(\mathbf{x})}{C_{1}(\mathbf{x})},\quad C_{1}(\mathbf{x})>0,\quad C_{2}(\mathbf{x})>0 \tag{22}
```

This formula is valid in the domain stated in Result 2.

###### Proof-sketch.

This is obtained by setting the first derivative of
$`\delta(\mathbf{x})`$, given in Result 2, with respect to $`t`$ to
zero.

### 3.6 Teacher-rewarded Best-of-$`k`$ Shows Power-law Decay

The low-$`T`$ result in Result 3 shows an inverse–quadratic $`k^{-2}`$
decay of the error when the reward matches the teacher
($`\mathbf{w}_{R}=\mathbf{w}_{T}`$). Here we sharpen that statement by
identifying a concrete, practically relevant parameter domain in which
the leading-order constant in front of $`k^{-2}`$ can be written in
closed form. Explicit formula clarifies how dimensionality, sample size,
noise, and prior scale combine in the low-temperature limit.

###### Remark 5.

As a refinement of Result 3, consider the parameter regime

```math
\frac{\gamma^{2}}{d}\text{Tr}(\mathbf{B}_{R}\bm{\Sigma})\ll\sigma^{2}.
```

In the low-temperature limit $`T\to 0`$ followed by $`k\to\infty`$, the
leading-order generalization error for
$`\mathbf{w}_{R}=\mathbf{w}_{T}=\mathbf{w}`$ is given by

```math
\delta\;=\frac{\pi\sigma^{2}}{k^{2}}\ \frac{1}{\sqrt{1-\frac{2}{\sigma^{2}d}\,\mathbf{u}^{\top}\bm{\Sigma}\mathbf{u}}},\quad\mathbf{u}:=\mathbf{B}_{R}\mathbf{w}
```

###### Proof-sketch.

In this domain the $`\mathbf{x}`$-dependence of $`s^{2}(\mathbf{x})`$ is
small relative to $`\sigma^{2}`$ and this allows us to reliably set
$`s^{2}(\mathbf{x})\approx\sigma^{2}`$ in Result 3 to evaluate the
expectation value.

In the flat prior limit, i.e, $`\gamma^{2}\gg\sigma^{2}`$, this regime
corresponds to ample amount of data per dimension, i.e., $`n\gg d`$. For
the isotropic sample covariance $`\bm{\Sigma}=S^{2}\mathbf{I}`$ that we
are analyzing in this paper, we have
$`\mathbf{u}=\frac{R}{R+S^{2}}\mathbf{w}`$. In the limit of flat prior
with ample amount of data, this further simplifies to
$`\mathbf{u}\approx(1/S^{2})(\sigma^{2}/\gamma^{2})(d/n)\mathbf{w}`$.
The Remark above shows as task difficulty increases, i.e, $`\sigma`$
gets larger keeping other parameters fixed, generalization error
$`\delta`$ and even the scaled generalization error
$`\delta/\sigma^{2}`$ increases.

### 3.7 Trade-off Between Training And Inference-time Compute

In practice we often face a budget allocation decision: should
additional compute be spent on _training_ (e.g., acquiring/processing
more samples $`n`$) or on _inference-time_ (e.g., drawing more
candidates $`k`$ and selecting via the reward)? When the reward is well
aligned with the teacher and we operate in the low-temperature regime,
best-of-$`k`$ style selection can substantially reduce error with
relatively modest inference cost. The question is how this compares with
the addition of more data.

###### Remark 6.

Given access to exact teacher weight, it is beneficial to scale
inference-time compute over adding more training samples in the
following regime: consider $`T\to 0`$ followed by $`k\to\infty`$ with

```math
\frac{\gamma^{2}}{d}\text{Tr}(\mathbf{B}_{R}\bm{\Sigma})\ll\sigma^{2},\quad R\ll\sigma^{2} \tag{23}
```

That is within this domain,

```math
\displaystyle\frac{\partial\log\delta}{\partial\log k}=-2,\qquad\frac{\partial\log\delta}{\partial\log n}=-\frac{\alpha\partial_{\alpha}\big(\mathbf{u}^{\top}\bm{\Sigma}\mathbf{u}\big)}{\sigma^{2}d-2\mathbf{u}^{\top}\bm{\Sigma}\mathbf{u}} \tag{24}
```

and hence

```math
\displaystyle\bigg|\frac{\partial\log\delta}{\partial\log k}\bigg|\gg\bigg|\frac{\partial\log\delta}{\partial\log n}\bigg| \tag{25}
```

###### Proof-sketch.

See Appendix E for details.

In the flat prior, i.e, $`\gamma^{2}\gg\sigma^{2}`$, ample data limit,
i.e., $`n\gg d`$, the second condition in the Remark quantifies prior
quality - roughly speaking it dictates that when the prior $`\gamma`$ is
broad enough, inference time compute is beneficial over training time
compute. For the isotropic sample covariance
$`\bm{\Sigma}=S^{2}\mathbf{I}`$, putting back explicit formula for
$`\mathbf{u}\approx R/S^{2}\mathbf{w}\approx(1/S^{2})(\sigma^{2}/\gamma^{2})(d/n)\mathbf{w}`$
shows that

```math
\displaystyle\frac{\partial\log\delta}{\partial\log n}=-2\frac{\frac{\mathbf{w}\cdot\mathbf{w}}{d}\frac{1}{S^{2}}\frac{d^{2}\sigma^{2}}{n^{2}\gamma^{4}}}{1-2\frac{\mathbf{w}\cdot\mathbf{w}}{d}\frac{1}{S^{2}}\frac{d^{2}\sigma^{2}}{n^{2}\gamma^{4}}} \tag{26}
```

In this case, under an even weaker condition $`R^{2}<\sigma^{2}`$
already we see that scaling inference time is beneficial over scaling
training compute. If $`\sigma`$ increases keeping other parameters held
fixed, the magnitude of the derivative of $`\log\delta`$ w.r.t.
$`\log n`$ increases. Hence as the task becomes more difficult the
advantage of inference time scaling degrades. The same statement holds
true if $`\gamma`$ decreases while other parameters are held fixed.

We empirically validate these results on advantages of inference-time
scaling over training compute in Figure 6(a). It is clear from Figure
6(a) that fractional increase in $`k`$ decreases generalization error
$`\delta`$ more compared to the same fractional increase in $`n`$ within
the domain of parameters considered in the plot. However, inference-time
scaling is not always advantageous over increasing training compute - we
explain this in Figure 6(b). We conclude that when we have access to a
good quality reward model and the task is easy enough, the addition of
inference time compute is beneficial over additional training compute.

In this section, we discuss implications of our theoretical results for
inference time scaling of large language models such as
Llama-3-8B-Instruct, DeepSeek-R1-Distill-Qwen-1.5B on openai/gsm8k
validation dataset (prompt included $`8`$ chain of thought
demonstrations). As the Judge model we used Mistral-7B-Instruct-v0.3 or

time samples. This fact has been observed in large language models in
(Snell et al., 2025; Chen et al., 2024a). Figure 7 shows that there is a
global minima in generalization error as a function of the inference

## 5 Conclusion and Limitations

We introduce a simple and analytically tractable model for studying
inference-time scaling, in which multiple candidate outputs are
generated and selected through a quadratic reward-based mechanism. Our
analysis shows that when the reward model is sufficiently well aligned
with the task, increasing the number of inference-time samples leads to
a reliable improvement in generalization. By contrast, when the reward
model is substantially misspecified, the generalization error becomes
non-monotonic, yielding both an optimal finite number of samples and an
optimal selection temperature. In the best-of-k regime with an ideal
reward model, we further identify a power-law scaling of the
generalization error. We complement the theory with experiments on large
language models evaluated on a mathematical reasoning benchmark, which
provide qualitative support for the predicted phenomena. To address the
simplified assumptions adopted in the main text, Appendix F discusses
how the framework extends more generally. At the same time, the LLM
experiments should be interpreted as qualitative validations rather than
literal recovery of theoretical parameters. Although Appendix F outlines
the formalism for heavy-tailed and potentially multimodal predictive
distributions, a careful analysis of these settings remains an open
problem.

We also show that the reward model achieving optimal performance need
not coincide with the teacher model. By exploiting structural properties
of the trained predictor, we derive the corresponding optimal reward
model within our framework. This suggests a possible analogue for large
language models: an auxiliary classifier could be used to identify
systematic weaknesses of the base model and to determine which queries
should be evaluated by the reward model, thereby enabling a form of
classifier-guided reward shaping. A thorough investigation of this
direction is left for future work.

In addition, we study the trade-off between training-time and
inference-time scaling. Extending this analysis in a careful and
realistic manner to large language models remains an important open
question.

Finally, the present work is limited to the i.i.d. sampling setting. In
Appendix G, we briefly outline how the framework may be extended to
non-i.i.d. sampling procedures, such as beam search and related decoding
strategies.

## Appendix A Review of extreme value statistics

### A.1 Limit Laws for Maxima

Here we note some of the useful results in extreme value theory from
\[de Haan and Ferreira, 2007\].

###### Result 4 (Fisher–Tippett–Gnedenko).

Let $`X_{1},X_{2},\dots`$ be i.i.d. non-degenerate random variables with
distribution function $`F`$, i.e,
$`F(x)=\mathbb{P}\!\left(X\leq x\right)`$, and let
$`M_{n}=\max\{X_{1},\dots,X_{n}\}`$. If there exist normalising
constants $`a_{n}>0`$ and $`b_{n}\in\mathbb{R}`$ and a non-degenerate
distribution function $`H`$ such that

```math
\mathbb{P}\!\left(\frac{M_{n}-b_{n}}{a_{n}}\leq x\right)\xrightarrow[n\to\infty]{}H(x)
```

then $`H`$ must be (up to affine change of variable) one of the three
_extreme value distributions_:

```math
\displaystyle\text{Fr\'{e}chet }(\alpha>0):\quad \displaystyle\Phi_{\alpha}(x)=\begin{cases}0,&x\leq 0,\\
\exp\!\{-x^{-\alpha}\},&x>0,\end{cases}
```

```math
\displaystyle\text{Weibull }(\alpha>0):\quad \displaystyle\Psi_{\alpha}(x)=\begin{cases}\exp\!\{-(-x)^{\alpha}\},&x\leq 0,\\
1,&x>0,\end{cases}
```

```math
\displaystyle\text{Gumbel}:\quad \displaystyle\Lambda(x)=\exp\!\{-e^{-x}\}, \displaystyle x\in\mathbb{R}.
```

### A.2 Maximum Domains of Attraction and Norming Constants

###### Definition 5 (Maximum domain of attraction).

We say $`F`$ belongs to the maximum domain of attraction of $`H`$ (write
$`F\in\mathrm{MDA}(H)`$) if there exist constants
$`a_{n}>0,b_{n}\in\mathbb{R}`$ such that

```math
\lim_{n\to\infty}F^{n}(a_{n}x+b_{n})=H(x)
```

###### Remark 7 (Characterisation via exceedance rates).

Let $`H`$ be a (standard) extreme value distribution. Then
$`F\in\mathrm{MDA}(H)`$ with norming constants
$`a_{n}>0,b_{n}\in\mathbb{R}`$ if and only if

```math
\lim_{n\to\infty}n\bigl(1-F(a_{n}x+b_{n})\bigr)=-\ln H(x)
```

For later convenience we define right endpoint
$`x_{F}:=\sup\{x:F(x)<1\}`$, complementary distribution function
$`\bar{F}(x):=1-F(x)`$ and quantile function
$`F^{\leftarrow}(t)=\inf\{x\in\mathbb{R}:F(x)\geq t\}`$.

#### A.2.1 The Maximum Domain of Attraction of the Fréchet Distribution

###### Result 6 (MDA of Fréchet).

Let $`F`$ have a finite right endpoint $`x_{F}=\infty`$ and and assume
there exists $`z<x_{F}`$ such that $`F`$ is differentiable in
$`(z,x_{F})`$ The following statements are equivalent:

1.  (i)
    $`F`$ satisfies _von Mises condition_, i.e.,

    ```math
    \lim_{x\to x_{F}-}\frac{x\,F^{\prime}(x)}{1-F(x)}=\alpha>0 \tag{28}
    ```

2.  (ii)
    $`F\in\mathrm{MDA}(\Phi_{\alpha})`$ with a possible choice of
    norming constants

    ```math
    b_{n}\;=0,\qquad a_{n}\;=F^{\leftarrow}\!\left(1-\frac{1}{n}\right),
    ```

#### A.2.2 The Maximum Domain of Attraction of the Weibull Distribution

###### Result 7 (MDA of Weibull).

Let $`F`$ have a finite right endpoint $`x_{F}<\infty`$ and and assume
there exists $`z<x_{F}`$ such that $`F`$ is differentiable in
$`(z,x_{F})`$ The following statements are equivalent:

1.  (i)
    $`F`$ satisfies _von Mises condition_, i.e.,

    ```math
    \lim_{x\to x_{F}-}\frac{(x_{F}-x)\,F^{\prime}(x)}{1-F(x)}=\alpha>0 \tag{29}
    ```

2.  (ii)
    $`F\in\mathrm{MDA}(\Psi_{\alpha})`$ with a possible choice of
    norming constants

    ```math
    b_{n}\;=\;x_{F},\qquad a_{n}\;=\;x_{F}-F^{\leftarrow}\!\left(1-\frac{1}{n}\right),
    ```

#### A.2.3 The Maximum Domain of Attraction of the Gumbel Distribution

###### Result 8 (MDA of Gumbel).

Let $`F`$ be a distribution with right endpoint $`x_{F}\leq\infty`$, and
assume there exists $`z<x_{F}`$ such that $`F`$ is at least twice
differentiable in $`(z,x_{F})`$. Define auxiliary function
$`a(x)=\bar{F}(x)/F^{\prime}(x)`$. The following statements are
equivalent:

1.  (i)
    $`F`$ is a von Mises function, i.e.,

    ```math
    \lim_{x\to x_{F}-}a^{\prime}(x)=0
    ```

2.  (ii)
    $`F\in MDA(\Lambda)`$ with a possible choice of norming constants

    ```math
    b_{n}\;=F^{\leftarrow}(1-1/n),\qquad a_{n}\;=\;a(b_{n})
    ```

## Appendix B Proof of Result 1

###### Result 9.

In the limit of $`d,n\to\infty`$, with $`\alpha=d/n<1`$ fixed, for
sufficiently small noise scale, i.e., there exists
$`\sigma_{c}(\alpha,R)`$ such that for
$`\sigma\ll\sigma_{c}(\alpha,R)`$, the generalization error is given by

```math
\displaystyle\delta=\mathbb{E}_{\mathbf{x}}\,\mathbb{E}_{y_{1},y_{2},..}\left[\frac{\sum_{i=1}^{k}\big(y_{i}-\mu_{T}(\mathbf{x})\big)^{2}\,e^{-\big(y_{i}-\mu_{R}(\mathbf{x})\big)^{2}/T}}{\sum_{j=1}^{k}e^{-\big(y_{j}-\mu_{R}(\mathbf{x})\big)^{2}/T}}\right], \tag{30}
```

to the leading order in $`\sigma`$. Here the expectation is over
$`\mathbf{x}\sim\mathcal{N}(0,\bm{\Sigma}),y_{i}\sim\mathcal{N}(m(\mathbf{x}),s(\mathbf{x})^{2}),i=1,2,\dots,k`$.
The posterior predictive has mean $`m(\mathbf{x})`$ and variance
$`\Sigma(\mathbf{x})=s(\mathbf{x})^{2}`$ as follows

```math
\displaystyle m(\mathbf{x})=\frac{\mathbf{x}}{\sqrt{d}}^{\top}\mathbf{A}_{R}\mathbf{w}_{T},\quad s(\mathbf{x})^{2}=\sigma^{2}+\gamma^{2}\,\frac{\mathbf{x}}{\sqrt{d}}^{\top}\mathbf{B}_{R}\,\frac{\mathbf{x}}{\sqrt{d}}. \tag{31}
```

The matrices $`\mathbf{A}_{R},\mathbf{B}_{R}`$ are given by

```math
\mathbf{A}_{R}:=\bm{\Sigma}(\bm{\Sigma}+R\mathbf{I})^{-1},\qquad\mathbf{B}_{R}:=R(\bm{\Sigma}+R\mathbf{I})^{-1}=\mathbf{I}-\mathbf{A}_{R}. \tag{32}
```

and the renormalized ridge $`R`$ is given by

```math
\displaystyle\hat{R}=R\Big(1-\alpha\,m_{\bm{\Sigma}}(R)\Big)=\frac{\sigma^{2}}{\gamma^{2}}\alpha, \tag{33}
```

```math
\displaystyle m_{\bm{\Sigma}}(R):=\frac{1}{d}\text{Tr}\!\big[\bm{\Sigma}(\bm{\Sigma}+RI)^{-1}\big].
```

###### Proof-sketch.

Let the empirical covariance be
$`\widehat{\bm{\Sigma}}:=\frac{1}{n}\sum_{i=1}^{n}\mathbf{x}^{i}{\mathbf{x}^{i}}^{\!\top}`$,
then

```math
\bm{\Omega}=\sigma^{2}\alpha\Big(\widehat{\bm{\Sigma}}+\hat{R}\,\mathbf{I}\Big)^{-1},\qquad\hat{R}:=\frac{\sigma^{2}}{\gamma^{2}}\,\alpha. \tag{34}
```

The mean of the predictive is given by

```math
\displaystyle m(\mathbf{x}) \displaystyle=\bm{\mu}^{\top}\frac{\mathbf{x}}{\sqrt{d}}=\frac{1}{\sigma^{2}}\,\frac{\mathbf{x}}{\sqrt{d}}^{\top}\bm{\Omega}\sum_{i=1}^{n}y^{i}\frac{\mathbf{x}^{i}}{\sqrt{d}} \tag{35}
```

```math
\displaystyle=\frac{\mathbf{x}}{\sqrt{d}}^{\top}\Big(\mathbf{I}-\frac{1}{\gamma^{2}}\bm{\Omega}\Big)\mathbf{w}_{T}\ +\ \frac{1}{\sigma^{2}}\,\frac{\mathbf{x}}{\sqrt{d}}^{\top}\bm{\Omega}\sum_{i=1}^{n}\eta^{i}\frac{\mathbf{x}^{i}}{\sqrt{d}}, \tag{36}
```

Now we use
$`\mathbf{I}-(1/\gamma^{2})\bm{\Omega}=\mathbf{I}-\hat{R}\Big(\widehat{\bm{\Sigma}}+\hat{R}\,\mathbf{I}\Big)^{-1}=\widehat{\bm{\Sigma}}\Big(\widehat{\bm{\Sigma}}+\hat{R}\,\mathbf{I}\Big)^{-1}`$
to get

```math
\displaystyle m(\mathbf{x}) \displaystyle=\big\langle\widehat{\bm{\Sigma}}\big(\widehat{\bm{\Sigma}}+\hat{R}\,\mathbf{I}\big)^{-1}\mathbf{w}_{T},\ \frac{\mathbf{x}}{\sqrt{d}}\big\rangle+\ \frac{1}{\sigma^{2}}\,\frac{\mathbf{x}}{\sqrt{d}}^{\top}\bm{\Omega}\sum_{i=1}^{n}\eta^{i}\frac{\mathbf{x}^{i}}{\sqrt{d}}, \tag{37}
```

Conditioned test data $`[\mathbf{x}^{1},\ldots,\mathbf{x}^{n}]`$ and the
test $`\mathbf{x}`$, the vector
$`\sum_{i=1}^{n}\eta^{i}\frac{\mathbf{x}^{i}}{\sqrt{d}}`$ has zero mean
with conditional covariance
$`\sigma^{2}\sum_{i=1}^{n}\frac{\mathbf{x}^{i}}{\sqrt{d}}\frac{\mathbf{x}^{i}}{\sqrt{d}}^{\!\top}`$.
When $`\sigma`$ is sufficiently small we can ignore this contribution.
We will present a detailed justification of this fact below.

The variance of the predictive can be simplified to

```math
\displaystyle s^{2}(\mathbf{x}) \displaystyle=\frac{\mathbf{x}}{\sqrt{d}}^{\top}\bm{\Omega}\,\frac{\mathbf{x}}{\sqrt{d}}+\sigma^{2}=\frac{\mathbf{x}}{\sqrt{d}}^{\top}\Big[\sigma^{2}\alpha\big(\widehat{\bm{\Sigma}}+\hat{R}\,\mathbf{I}\big)^{-1}\Big]\frac{\mathbf{x}}{\sqrt{d}}+\sigma^{2}
```

```math
\displaystyle=\gamma^{2}\,\frac{\mathbf{x}}{\sqrt{d}}^{\top}\Big[\hat{R}\big(\widehat{\bm{\Sigma}}+\hat{R}\,\mathbf{I}\big)^{-1}\Big]\frac{\mathbf{x}}{\sqrt{d}}+\sigma^{2}, \tag{38}
```

There exists a $`R>0`$ as defined in the Result such that, for any
vectors $`u,v`$ with bounded norms,

```math
\displaystyle u^{\top}\!\Big[\widehat{\bm{\Sigma}}\big(\widehat{\bm{\Sigma}}+\hat{R}\,\mathbf{I}\big)^{-1}\Big]v \displaystyle\ \xrightarrow{\;p\;}\ u^{\top}\!\big[\bm{\Sigma}(\bm{\Sigma}+R\mathbf{I})^{-1}\big]v\ =\ u^{\top}\mathbf{A}_{R}v, \tag{39}
```

```math
\displaystyle u^{\top}\!\Big[\hat{R}\,\big(\widehat{\bm{\Sigma}}+\hat{R}\,\mathbf{I}\big)^{-1}\Big]v \displaystyle\ \xrightarrow{\;p\;}\ u^{\top}\!\big[R(\bm{\Sigma}+R\mathbf{I})^{-1}\big]v\ =\ u^{\top}\mathbf{B}_{R}v. \tag{40}
```

Applying equation 39 to equation 37, yields

```math
m(\mathbf{x})\ \xrightarrow{\;p\;}\ \frac{\mathbf{x}}{\sqrt{d}}^{\top}\mathbf{A}_{R}\mathbf{w}_{T}
```

Applying equation 40 to equation 38 with
$`u=v=\frac{\mathbf{x}}{\sqrt{d}}`$ yields

```math
s^{2}(\mathbf{x})\ \xrightarrow{\;p\;}\ \sigma^{2}+\gamma^{2}\,\frac{\mathbf{x}}{\sqrt{d}}^{\top}\mathbf{B}_{R}\,\frac{\mathbf{x}}{\sqrt{d}}.
```

Now we turn to give a precise condition for when it is suitable to drop
the noise term. Define

```math
Z(\mathbf{x}):=\frac{1}{\sigma^{2}}\,\frac{\mathbf{x}}{\sqrt{d}}^{\top}\bm{\Omega}\sum_{i=1}^{n}\eta^{i}\frac{\mathbf{x}^{i}}{\sqrt{d}}. \tag{41}
```

Then, in the proportional limit $`d,n\to\infty`$ with $`\alpha`$ fixed,
the variance of the label–noise term $`Z(\mathbf{x})`$ admits the
deterministic equivalent

```math
\displaystyle\mathrm{Var}\big(Z(\mathbf{x})\big)\;\xrightarrow[d,n\to\infty]{}\;\sigma^{2}\,\frac{\alpha\,m_{\bm{\Sigma}}^{(2)}(R)}{1-\alpha\,m_{\bm{\Sigma}}^{(2)}(R)}, \tag{42}
```

```math
\displaystyle m_{\bm{\Sigma}}^{(2)}(R):=\frac{1}{d}\text{Tr}\!\big[\bm{\Sigma}^{2}(\bm{\Sigma}+R\mathbf{I})^{-2}\big]
```

Next we explain this. Conditioned on the training inputs
$`\{\mathbf{x}^{i}\}_{i=1}^{n}`$ and the test point $`\mathbf{x}`$.
Using equation 41 and the fact that
$`\bm{\eta}=(\eta^{1},\dots,\eta^{n})^{\top}\sim\mathcal{N}(0,\sigma^{2}\mathbf{I}_{n})`$
is independent of $`\mathcal{D}`$ and $`\mathbf{x}`$, we have

```math
Z(\mathbf{x})=\frac{1}{\sigma^{2}}\,\frac{\mathbf{x}}{\sqrt{d}}^{\top}\bm{\Omega}\sum_{i=1}^{n}\eta^{i}\frac{\mathbf{x}^{i}}{\sqrt{d}}=\frac{1}{\sigma^{2}}\,\frac{\mathbf{x}}{\sqrt{d}}^{\top}\bm{\Omega}\widetilde{X}^{\top}\bm{\eta},
```

where $`\widetilde{X}\in\mathbb{R}^{n\times d}`$ has rows
$`{\frac{\mathbf{x}^{i}}{\sqrt{d}}}^{\top}`$. Hence

```math
\mathbb{E}\big[Z(\mathbf{x})\mid\mathcal{D},\mathbf{x}\big]=0,
```

and

```math
\mathrm{Cov}\big(\widetilde{X}^{\top}\bm{\eta}\,\big|\,\mathcal{D}\big)=\mathbb{E}\big[\widetilde{X}^{\top}\bm{\eta}\bm{\eta}^{\top}\widetilde{X}\mid\mathcal{D}\big]=\sigma^{2}\sum_{i=1}^{n}\frac{\mathbf{x}^{i}}{\sqrt{d}}{\frac{\mathbf{x}^{i}}{\sqrt{d}}}^{\top}.
```

Therefore

```math
\displaystyle\mathrm{Var}\big(Z(\mathbf{x})\mid\mathcal{D},\mathbf{x}\big) \displaystyle=\frac{1}{\sigma^{4}}\,\frac{\mathbf{x}}{\sqrt{d}}^{\top}\bm{\Omega}\mathrm{Cov}\big(\widetilde{X}^{\top}\bm{\eta}\mid\mathcal{D}\big)\bm{\Omega}^{\top}\frac{\mathbf{x}}{\sqrt{d}}
```

```math
\displaystyle=\frac{1}{\sigma^{4}}\,\frac{\mathbf{x}}{\sqrt{d}}^{\top}\bm{\Omega}\Big(\sigma^{2}\sum_{i=1}^{n}\frac{\mathbf{x}^{i}}{\sqrt{d}}{\frac{\mathbf{x}^{i}}{\sqrt{d}}}^{\top}\Big)\bm{\Omega}^{\top}\frac{\mathbf{x}}{\sqrt{d}}
```

```math
\displaystyle=\frac{1}{\sigma^{2}}\,\frac{\mathbf{x}}{\sqrt{d}}^{\top}\bm{\Omega}\Big(\sum_{i=1}^{n}\frac{\mathbf{x}^{i}}{\sqrt{d}}{\frac{\mathbf{x}^{i}}{\sqrt{d}}}^{\top}\Big)\bm{\Omega}^{\top}\frac{\mathbf{x}}{\sqrt{d}}. \tag{43}
```

Recall that
$`\widehat{\bm{\Sigma}}:=\tfrac{1}{n}\sum_{i=1}^{n}\mathbf{x}^{i}{\mathbf{x}^{i}}^{\top}`$.
Then

```math
\displaystyle\sum_{i=1}^{n}\frac{\mathbf{x}^{i}}{\sqrt{d}}{\frac{\mathbf{x}^{i}}{\sqrt{d}}}^{\top}=\frac{1}{d}\sum_{i=1}^{n}\mathbf{x}^{i}{\mathbf{x}^{i}}^{\top}=\frac{n}{d}\,\widehat{\bm{\Sigma}}=\frac{1}{\alpha}\,\widehat{\bm{\Sigma}}, \tag{44}
```

```math
\displaystyle\bm{\Omega}=\sigma^{2}\alpha(\widehat{\bm{\Sigma}}+\hat{R}\mathbf{I})^{-1}.
```

Substituting this into equation 43 yields

```math
\displaystyle\mathrm{Var}\big(Z(\mathbf{x})\mid\mathcal{D},\mathbf{x}\big) \tag{45}
```

```math
\displaystyle=\frac{1}{\sigma^{2}\alpha}\,\frac{\mathbf{x}}{\sqrt{d}}^{\top}\bigl[\sigma^{2}\alpha(\widehat{\bm{\Sigma}}+\hat{R}\mathbf{I})^{-1}\bigr]\widehat{\bm{\Sigma}}\bigl[\sigma^{2}\alpha(\widehat{\bm{\Sigma}}+\hat{R}\mathbf{I})^{-1}\bigr]\frac{\mathbf{x}}{\sqrt{d}}
```

```math
\displaystyle=\sigma^{2}\alpha\,\frac{\mathbf{x}}{\sqrt{d}}^{\top}(\widehat{\bm{\Sigma}}+\hat{R}\mathbf{I})^{-1}\widehat{\bm{\Sigma}}(\widehat{\bm{\Sigma}}+\hat{R}\mathbf{I})^{-1}\frac{\mathbf{x}}{\sqrt{d}}. \tag{46}
```

Let $`\mathbf{x}\sim\mathcal{N}(0,\bm{\Sigma})`$ be independent of
$`\mathcal{D}`$, and recall
$`\frac{\mathbf{x}}{\sqrt{d}}=\mathbf{x}/\sqrt{d}`$. For any fixed
$`d\times d`$ matrix $`A`$,

```math
\mathbb{E}_{\mathbf{x}}\big[\frac{\mathbf{x}}{\sqrt{d}}^{\top}A\,\frac{\mathbf{x}}{\sqrt{d}}\big]=\frac{1}{d}\,\mathbb{E}_{\mathbf{x}}\big[\mathbf{x}^{\top}A\,\mathbf{x}\big]=\frac{1}{d}\,\text{Tr}(A\bm{\Sigma}).
```

Applying this to equation 46 gives

```math
\displaystyle\mathbb{E}_{\mathbf{x}}\big[\mathrm{Var}(Z(\mathbf{x})\mid\mathcal{D},\mathbf{x})\big] \tag{47}
```

```math
\displaystyle=\sigma^{2}\alpha\,\frac{1}{d}\,\text{Tr}\Big((\widehat{\bm{\Sigma}}+\hat{R}\mathbf{I})^{-1}\widehat{\bm{\Sigma}}(\widehat{\bm{\Sigma}}+\hat{R}\mathbf{I})^{-1}\bm{\Sigma}\Big).
```

Since $`\mathbb{E}[Z(\mathbf{x})\mid\mathcal{D},\mathbf{x}]=0`$, the
unconditional variance is

```math
\displaystyle\mathrm{Var}\big(Z(\mathbf{x})\big) \displaystyle=\mathbb{E}_{\mathcal{D},\mathbf{x}}\big[\mathrm{Var}(Z(\mathbf{x})\mid\mathcal{D},\mathbf{x})\big], \tag{48}
```

so taking expectation over $`\mathcal{D}`$ in equation 47 yields

```math
\mathrm{Var}\big(Z(\mathbf{x})\big)=\sigma^{2}\alpha\,\mathbb{E}_{\mathcal{D}}\left[\frac{1}{d}\,\text{Tr}\Big((\widehat{\bm{\Sigma}}+\hat{R}\mathbf{I})^{-1}\widehat{\bm{\Sigma}}(\widehat{\bm{\Sigma}}+\hat{R}\mathbf{I})^{-1}\bm{\Sigma}\Big)\right]. \tag{49}
```

We now invoke the same deterministic–equivalent machinery. One obtains

```math
\frac{1}{d}\,\text{Tr}\Big((\widehat{\bm{\Sigma}}+\hat{R}\mathbf{I})^{-1}\widehat{\bm{\Sigma}}(\widehat{\bm{\Sigma}}+\hat{R}\mathbf{I})^{-1}\bm{\Sigma}\Big)\;\xrightarrow[d,n\to\infty]{\mathbb{P}}\;\frac{\alpha\,m_{\bm{\Sigma}}^{(2)}(R)}{1-\alpha\,m_{\bm{\Sigma}}^{(2)}(R)}, \tag{50}
```

where

```math
m_{\bm{\Sigma}}^{(2)}(R)=\frac{1}{d}\text{Tr}\big[\bm{\Sigma}^{2}(\bm{\Sigma}+R\mathbf{I})^{-2}\big].
```

Substituting the deterministic equivalent equation 50 into equation 49,
we obtain, as $`d,n\to\infty`$ with $`\alpha`$ fixed,

```math
\displaystyle\mathrm{Var}\big(Z(\mathbf{x})\big) \displaystyle=\sigma^{2}\alpha\,\frac{1}{d}\,\text{Tr}\Big((\widehat{\bm{\Sigma}}+\hat{R}\mathbf{I})^{-1}\widehat{\bm{\Sigma}}(\widehat{\bm{\Sigma}}+\hat{R}\mathbf{I})^{-1}\bm{\Sigma}\Big) \tag{51}
```

```math
\displaystyle=\sigma^{2}\,\frac{\alpha\,m_{\bm{\Sigma}}^{(2)}(R)}{1-\alpha\,m_{\bm{\Sigma}}^{(2)}(R)}.
```

Here we can ignore this contribution as long as

```math
\sigma^{2}\ll\frac{1-\alpha\,m_{\bm{\Sigma}}^{(2)}(R)}{\alpha\,m_{\bm{\Sigma}}^{(2)}(R)}=\sigma_{c}(\alpha,R)^{2} \tag{52}
```

## Appendix D Proof of Result 3

###### Result 11 (Low-$`T`$ best-of-$`k`$ sampling).

When we have access to the exact teacher weight
$`\mathbf{w}_{R}=\mathbf{w}_{T}=\mathbf{w}`$, the leading order result
for $`T\to 0`$ followed by $`k\to\infty`$ is given by

```math
\delta(\mathbf{x})\;=\;\frac{\pi}{k^{2}}\ s^{2}(\mathbf{x})\ \exp\!\left(\frac{\Delta_{T}(\mathbf{x})^{2}}{s^{2}(\mathbf{x})}\right)\  \tag{66}
```

All the quantities are as in Result 1 and Result 2.

###### Proof-sketch.

In $`T\to 0`$ limit it is natural to approximate the softmax by the
sample with highest reward, i.e.,

```math
\displaystyle\delta(\mathbf{x}) \displaystyle=\mathbb{E}_{y_{i}\sim\mathcal{N}(m,\Sigma),i=1,\ldots,k}\bigg(\left(y^{\prime}_{k}-\mathbf{w}_{T}\cdot\frac{\mathbf{x}}{\sqrt{d}}\right)^{2}: \tag{67}
```

```math
\displaystyle y^{\prime}_{k}=\text{arg min}_{y\in(y_{1},y_{2},..,y_{k})}\left(y-\mathbf{w}_{R}\cdot\frac{\mathbf{x}}{\sqrt{d}}\right)^{2}\bigg)
```

First note that the distribution of the penalty is a non-central
chi-squared distribution with one degree of freedom:

```math
\displaystyle-v\equiv\frac{1}{s^{2}}\left(y-\mathbf{w}_{R}\cdot\frac{\mathbf{x}}{\sqrt{d}}\right)^{2}\sim\chi_{1}^{2}\left(\lambda\right),\lambda=\frac{(m-\mathbf{w}_{R}\cdot\frac{\mathbf{x}}{\sqrt{d}})^{2}}{s^{2}} \tag{68}
```

We focus on the situation of perfect reward
$`\mathbf{w}_{R}=\mathbf{w}_{T}`$ in the high reward regime. In this
case,

```math
\displaystyle\delta(\mathbf{x})=s^{2}\mathbb{E}(-v_{max}),\quad v_{max}=\text{max}_{-v_{i}\sim\chi_{1}^{2}(\lambda)}(v_{1},v_{2},..,v_{k}) \tag{69}
```

Since we are looking for the minimum of the chi-squared distributed
variables the extreme value statistics is more involved and the final
distribution is different compared to the analysis for maximum.

Next we focus on $`k\to\infty`$ limit for analytical tractability.
Probability distribution function $`\varphi`$ and cumulative
distribution function $`F`$ of $`v\leq 0`$ is given by

```math
\displaystyle\varphi(v)=\frac{e^{\frac{v-\lambda}{2}}\cos\left(\sqrt{\lambda v}\right)}{\sqrt{2\pi}\sqrt{-v}}, \tag{70}
```

```math
\displaystyle F(v)=1-\frac{1}{2}\left(\text{erf}\left(\frac{\sqrt{-v}-\sqrt{\lambda}}{\sqrt{2}}\right)+\text{erf}\left(\frac{\sqrt{\lambda}+\sqrt{-v}}{\sqrt{2}}\right)\right)
```

Note that as $`k\to\infty`$ the degenerate distribution concentrates
near $`v_{F}=0`$. Given that $`v_{F}`$ is finite, the extreme
distribution could be either of Weibull or Gumbel type. Next we show
that it is not Gumbel type. To see this we calculate the auxiliary
function for the Gumbel type using

```math
\displaystyle a(v)=\frac{1-F(v)}{F^{\prime}(v)},\quad\lim_{v\to v_{F}}a^{\prime}(v)\neq 0 \tag{71}
```

This limit on right ensures it cannot be of Gumbel type. To identify the
Weibull distribution

```math
\displaystyle\Psi_{\alpha}(x)=e^{-(-x)^{\alpha}}\quad\text{for }x\leq 0,\quad 1\quad\text{otherwise} \tag{72}
```

We calculate

```math
\displaystyle\alpha=\lim_{v\to v_{F}}\frac{(v_{F}-v)F^{\prime}(v)}{1-F(x)}=\frac{1}{2} \tag{73}
```

This ensures the cumulative distribution function of
$`(v_{max}-d_{k})/c_{k}`$ is $`\Psi_{\alpha}`$ where

```math
\displaystyle d_{k}=v_{F}=0 \tag{74}
```

```math
\displaystyle c_{k}=v_{F}-F^{\leftarrow}\left(1-\frac{1}{k}\right)=\frac{\pi}{2k^{2}}e^{\lambda}
```

The probability density for $`-v_{max}/c_{k}`$ is

```math
\displaystyle p_{max}(-v_{max}/c_{k})=\alpha(-v_{max}/c_{k})^{\alpha-1}e^{-(-v_{max}/c_{k})^{\alpha}},\quad v_{max}\leq 0 \tag{75}
```

This gives the following expression for the error in
$`t\to 0,k\to\infty`$ limit (taken in this order)

```math
\displaystyle\delta(\mathbf{x}) \displaystyle=s^{2}c_{k}\mathbb{E}(-v_{max}/c_{k}) \tag{76}
```

```math
\displaystyle=s^{2}c_{k}\Gamma(1+1/\alpha)
```

```math
\displaystyle=\frac{\pi s^{2}}{k^{2}}e^{\frac{(m-\mathbf{w}\cdot\frac{\mathbf{x}}{\sqrt{d}})^{2}}{s^{2}}}
```

## Appendix E Proof of Remark 6

###### Remark 8.

Given access to exact teacher weight, it is beneficial to scale
inference-time compute over adding more training samples in the
following regime: consider $`T\to 0`$ followed by $`k\to\infty`$ with

```math
\frac{\gamma^{2}}{d}\text{Tr}(\mathbf{B}_{R}\bm{\Sigma})\ll\sigma^{2},\quad R\ll\sigma^{2} \tag{77}
```

That is within this domain,

```math
\displaystyle\frac{\partial\log\delta}{\partial\log k}=-2,\qquad\frac{\partial\log\delta}{\partial\log n}=-\frac{\alpha\partial_{\alpha}\big(\mathbf{u}^{\top}\bm{\Sigma}\mathbf{u}\big)}{\sigma^{2}d-2\mathbf{u}^{\top}\bm{\Sigma}\mathbf{u}} \tag{78}
```

and hence

```math
\displaystyle\bigg|\frac{\partial\log\delta}{\partial\log k}\bigg|\gg\bigg|\frac{\partial\log\delta}{\partial\log n}\bigg| \tag{79}
```

###### Proof-sketch.

Our goal is to put upper bound on the magnitude of the derivative w.r.t.
$`n`$. We proceed systematically by working in the eigen basis of sample
variance. By the spectral Theorem for real symmetric matrices, there
exists an orthogonal matrix $`Q\in O(d)`$ and a diagonal
$`\Lambda=\mathrm{diag}(\lambda_{1},\dots,\lambda_{d})`$ with
$`\lambda_{i}\geq 0`$ such that

```math
\bm{\Sigma}=Q\Lambda Q^{\top},\qquad\mathbf{B}_{R}=Q\,\mathrm{diag}\!\Bigl(\frac{R}{\lambda_{i}+R}\Bigr)Q^{\top}.
```

This immediately gives following inequalities

```math
\displaystyle m_{\bm{\Sigma}}(R)=\frac{1}{d}\text{Tr}\!\big[\bm{\Sigma}(\bm{\Sigma}+R\mathbf{I})^{-1}\big]=\frac{1}{d}\sum_{i=1}^{d}\frac{\lambda_{i}}{\lambda_{i}+R}<1 \tag{80}
```

```math
\displaystyle m_{\bm{\Sigma}}^{\prime}(R)=-\frac{1}{d}\text{Tr}\!\big[\bm{\Sigma}(\bm{\Sigma}+R\mathbf{I})^{-2}\big]=-\frac{1}{d}\sum_{i=1}^{d}\frac{\lambda_{i}}{(\lambda_{i}+R)^{2}}\leq 0 \tag{81}
```

We are interested in putting upper bound on the following quantity

```math
\displaystyle\alpha\,\partial_{\alpha}(\bm{u}^{\top}\bm{\Sigma}\,\bm{u})=\alpha\,F^{\prime}(R)\,\frac{dR}{d\alpha}, \tag{82}
```

```math
\displaystyle F(R)=\bm{u}^{\top}\bm{\Sigma}\,\bm{u}=\sum_{i=1}^{d}\frac{R^{2}\lambda_{i}}{(\lambda_{i}+R)^{2}}\,\tilde{w}_{i}^{\,2}\;,\quad\tilde{\bm{w}}=Q^{\top}\bm{w}
```

We will first derive an upper bound on $`F^{\prime}(R)`$ and an upper
bound on $`\frac{dR}{d\alpha}`$. To this goal we proceed by noting that
$`\max_{\lambda\geq 0}\frac{\lambda^{2}}{(\lambda+R)^{3}}=\frac{4}{27}\,\frac{1}{R}`$
(attained at $`\lambda=2R`$) and we have

```math
F^{\prime}(R)=\sum_{i=1}^{d}\frac{2R\,\lambda_{i}^{2}}{(\lambda_{i}+R)^{3}}\,\tilde{w}_{i}^{2}\leq 2R\cdot\frac{4}{27}\frac{1}{R}\,\|\bm{w}\|^{2}=\frac{8}{27}\,d.
```

Next we focus on the deterministic equivalents equation

```math
\hat{R}=R\bigl(1-\alpha m_{\bm{\Sigma}}(R)\bigr),\qquad\hat{R}=\frac{\sigma^{2}\alpha}{\gamma^{2}}.
```

Differentiate both sides w.r.t. $`\alpha`$:

```math
\Bigl((1-\alpha m_{\bm{\Sigma}})-\alpha Rm^{\prime}_{\bm{\Sigma}}\Bigr)\,R^{\prime}=\frac{\sigma^{2}}{\gamma^{2}}+R\,m_{\bm{\Sigma}}(R).
```

Using the inequalities in equation (80)

```math
R^{\prime}\ \leq\ \frac{\frac{\sigma^{2}}{\gamma^{2}}+R\,m_{\bm{\Sigma}}(R)}{\hat{R}/R}\ \leq\ \frac{\frac{\sigma^{2}}{\gamma^{2}}+R}{\hat{R}/R}=\frac{\sigma^{2}}{\gamma^{2}}\,\frac{R}{\hat{R}}+\frac{R^{2}}{\hat{R}}.
```

This gives us the desired upper bound

```math
\alpha\,\partial_{\alpha}(\bm{u}^{\top}\bm{\Sigma}\,\bm{u})=\alpha\,F^{\prime}(R)\,\frac{dR}{d\alpha}\;\leq\;\frac{8}{27}\,d\Bigl(R+\frac{\gamma^{2}R^{2}}{\sigma^{2}}\Bigr).
```

Finally we aim for establishing a lower bound on
$`\sigma^{2}d-2\,\bm{u}^{\top}\bm{\Sigma}\,\bm{u}`$. This is achieved by
the following observation

```math
\frac{R^{2}\lambda}{(\lambda+R)^{2}}\ \leq\ \frac{R^{2}(\lambda+R)}{(\lambda+R)^{2}}=\frac{R^{2}}{\lambda+R}\ \leq\ R,
```

Hence

```math
\bm{u}^{\top}\bm{\Sigma}\,\bm{u}\ =\sum_{i=1}^{d}\frac{R^{2}\lambda_{i}}{(\lambda_{i}+R)^{2}}\,\tilde{w}_{i}^{\,2}\leq\ R\sum_{i=1}^{d}\tilde{w}_{i}^{\,2}=R\,\|\bm{w}\|^{2}=R\,d.
```

Therefore

```math
\sigma^{2}d-2\,\bm{u}^{\top}\bm{\Sigma}\,\bm{u}\ \geq\ d\,(\sigma^{2}-2R).
```

Putting both the results together, when $`R/\sigma^{2}\ll 1`$ we get

```math
\left|\frac{\partial\log\delta}{\partial\log n}\right|\ \leq\ \cdot\frac{\frac{8}{27}\,d\,(R+\gamma^{2}R^{2}/\sigma^{2})}{d(\sigma^{2}-2R)}\ =\ \frac{8}{27}\cdot\frac{R}{\sigma^{2}}\cdot\frac{1+\gamma^{2}R/\sigma^{2}}{1-2R/\sigma^{2}}\ \ll 1
```

## Appendix F Inference time scaling of generic probabilistic models

Let $`p_{\mathbf{x}}(y):=p(y\mid\mathbf{x},\mathcal{D})`$ be an
arbitrary predictive distribution for a fixed input $`\mathbf{x}`$, let
$`r(y,\mathbf{x})`$ be an arbitrary reward, and let
$`\ell(y,\mathbf{x})`$ be the task loss we care about. Define the
finite-sample reranked loss

```math
\delta_{k}^{(\ell,r)}(\mathbf{x},T):=\mathbb{E}_{Y_{1:k}\sim p_{\mathbf{x}}}\left[\frac{\sum_{i=1}^{k}\ell(Y_{i},\mathbf{x})e^{r(Y_{i},\mathbf{x})/T}}{\sum_{j=1}^{k}e^{r(Y_{j},\mathbf{x})/T}}\right]. \tag{83}
```

_(a) High-temperature regime._

Expanding in $`\varepsilon:=1/T`$ gives
$`e^{\varepsilon r}=1+\varepsilon r+\frac{\varepsilon^{2}}{2}r^{2}+O(\varepsilon^{3}),`$
and a direct expansion yields

```math
\displaystyle\delta_{k}^{(\ell,r)}(\mathbf{x},T) \displaystyle=\mu_{\ell}(\mathbf{x})+\frac{k-1}{k}\frac{1}{T}\,\mathrm{Cov}_{x}(\ell,r)
```

```math
\displaystyle\quad+\frac{(k-1)(k-2)}{2k^{2}}\frac{1}{T^{2}}\mathrm{Cov}_{x}\big(\ell,(r-\mu_{r}(\mathbf{x}))^{2}\big)
```

```math
\displaystyle\quad+O(T^{-3}) \tag{84}
```

where
$`\mu_{\ell}(\mathbf{x}):=\mathbb{E}_{p_{\mathbf{x}}}[\ell(Y,\mathbf{x})],\mu_{r}(\mathbf{x}):=\mathbb{E}_{p_{\mathbf{x}}}[r(Y,\mathbf{x})],`$
and $`\mathrm{Cov}_{x}`$ denotes covariance under
$`Y\sim p_{\mathbf{x}}`$.

_First-order term._ The leading correction is
$`\frac{k-1}{k}\frac{1}{T}\,\mathrm{Cov}_{x}(\ell,r).`$ Hence, to first
order, reranking is beneficial precisely when
$`\mathrm{Cov}_{x}(\ell,r)<0,`$ that is, when larger reward is
correlated with smaller task loss under the base predictive
distribution. This conclusion is completely general. Moreover, at this
order:

- •
  the dependence on $`k`$ is monotone, since it enters only through
  $`(k-1)/k`$;
- •
  the dependence on $`T`$ is monotone, since the correction scales as
  $`1/T`$;
- •
  therefore neither an optimal temperature nor a finite optimal $`k`$
  can appear at first order alone.

In the asymptotic high-$`T`$ regime where the first-order term
dominates, only the basic alignment effect survives.

_Second-order term._ The next coefficient is
$`\frac{(k-1)(k-2)}{2k^{2}}\frac{1}{T^{2}}\mathrm{Cov}_{x}\big(\ell,(r-\mu_{r}(\mathbf{x}))^{2}\big).`$
This term is still completely general, this term measures how the
fluctuation of the reward correlates with the task loss. More
explicitly:

- •
  If $`\mathrm{Cov}_{x}\big(\ell,(r-\mu_{r})^{2}\big)>0,`$ then
  higher-loss draws tend to occur where the reward fluctuates more
  strongly around its mean. In that case, aggressive reranking can
  over-amplify reward noise or reward misspecification, which is exactly
  the mechanism that can generate a finite optimal temperature or a
  finite optimal sample budget.
- •
  If $`\mathrm{Cov}_{x}\big(\ell,(r-\mu_{r})^{2}\big)<0,`$ then
  lower-loss draws tend to come with larger reward spread. In that case,
  the second-order correction helps the selector distinguish good draws
  more strongly, and reranking remains helpful.

The expansion equation 84 does not use Gaussianity. It only requires the
relevant moments to exist under $`p_{\mathbf{x}}`$. So in the
high-temperature regime, what Gaussianity gives us is an analytically
tractable closed form for those moments and can be easily generalized to
heavy-tailed or multi-modal distributions.

The main text in the paper corresponds to the following choice
$`\ell(y,\mathbf{x})=(y-\mu_{T}(\mathbf{x}))^{2},r(y,\mathbf{x})=-(y-\mu_{R}(\mathbf{x}))^{2},p_{\mathbf{x}}=f_{x}:=\mathcal{N}(m(\mathbf{x}),s(\mathbf{x})^{2}).`$
This choice allows us to explicitly perform calculation of the
quantities appearing above.

_(b) Low-temperature regime._

Here the key object is not the global shape of the predictive
distribution, but its local behavior near the reward maximizer. If the
judge-induced score $`r(y,\mathbf{x})`$ is smooth and has a local
maximizer $`y_{\star}(\mathbf{x})`$, then

```math
\displaystyle r(y,\mathbf{x})=r(y_{\star},\mathbf{x})-\frac{\kappa(\mathbf{x})}{2}\bigl(y-y_{\star}(\mathbf{x})\bigr)^{2}+O\!\left(|y-y_{\star}(\mathbf{x})|^{3}\right), \tag{85}
```

with $`\kappa(\mathbf{x}):=-\partial_{y}^{2}r(y_{\star},\mathbf{x})>0`$.
Thus, locally, the reward-weighted selector behaves like our quadratic
model with

```math
\mu_{R}(\mathbf{x})=y_{\star}(\mathbf{x}). \tag{86}
```

The additive constant $`r(y_{\star},\mathbf{x})`$ drops out of the
softmax, while $`\kappa(\mathbf{x})`$ simply rescales $`T`$. Hence, when
$`T`$ is small, only samples very close to $`\mu_{R}(\mathbf{x})`$
matter, so the quadratic approximation is the correct universal local
model. We therefore focus on $`T=0`$.

We will find following definition useful for
$`Y_{i}\stackrel{{\scriptstyle\mathrm{iid}}}{{\sim}}p_{\mathbf{x}}`$

```math
\displaystyle Y_{(R)}(\mathbf{x}):=\arg\min_{1\leq i\leq k}|Y_{i}-\mu_{R}(\mathbf{x})|,S_{k}(\mathbf{x}):=Y_{(R)}(\mathbf{x})-\mu_{R}(\mathbf{x}). \tag{87}
```

Define the local density around the reward target by

```math
g_{R,\mathbf{x}}(u):=p_{\mathbf{x}}(\mu_{R}(\mathbf{x})+u). \tag{88}
```

Assume that

```math
\displaystyle g_{R,\mathbf{x}}(u)=c_{R,\mathbf{x}}|u|^{\beta}+d_{R,\mathbf{x}}u|u|^{\beta}+o(|u|^{\beta+1}),\qquad u\to 0. \tag{89}
```

Then ‘coverage’ is given by

```math
\displaystyle H_{R,\mathbf{x}}(r) \displaystyle:=\Pr\bigl(|Y-\mu_{R}(\mathbf{x})|\leq r\mid\mathbf{x}\bigr)=\int_{-r}^{r}g_{R,\mathbf{x}}(u)\,du \tag{90}
```

```math
\displaystyle=2c_{R,\mathbf{x}}\int_{0}^{r}u^{\beta}\,du+o(r^{\beta+1})
```

```math
\displaystyle=:A_{R,\mathbf{x}}r^{\beta+1}+o(r^{\beta+1}),\qquad A_{R,\mathbf{x}}:=\frac{2c_{R,\mathbf{x}}}{\beta+1}.
```

Therefore for small $`r`$

```math
\Pr\bigl(|S_{k}(\mathbf{x})|>r\mid\mathbf{x}\bigr)=\bigl(1-H_{R,\mathbf{x}}(r)\bigr)^{k}\approx\exp\bigl(-kA_{R,\mathbf{x}}r^{\beta+1}\bigr), \tag{91}
```

and integration by parts gives

```math
\displaystyle\mathbb{E}[S_{k}(\mathbf{x})^{2}\mid\mathbf{x}] \displaystyle=2\int_{0}^{\infty}r\,\Pr\bigl(|S_{k}(\mathbf{x})|>r\mid\mathbf{x}\bigr)\,dr \tag{92}
```

```math
\displaystyle\approx 2\int_{0}^{\infty}r\,e^{-kA_{R,\mathbf{x}}r^{\beta+1}}\,dr
```

```math
\displaystyle=\frac{2}{\beta+1}A_{R,\mathbf{x}}^{-\frac{2}{\beta+1}}\Gamma\!\left(\frac{2}{\beta+1}\right)k^{-\frac{2}{\beta+1}}.
```

Here we used the fact that for large $`k`$, significant contribution
comes from small $`r`$ region.

When $`\mu_{R}(\mathbf{x})=\mu_{T}(\mathbf{x})`$, this is exactly the
generalization error:

```math
\mathbb{E}\bigl[(Y_{(R)}-\mu_{T}(\mathbf{x}))^{2}\mid\mathbf{x}\bigr]\asymp k^{-\frac{2}{\beta+1}}.
```

Hence in this case the decay of the generalization error is governed by
the ‘coverage’ near the target. For the Gaussian case in the main text,
$`\beta=0`$, so we recover the $`k^{-2}`$ law.

Since ties occur with probability zero under a continuous density, the
density of $`S_{k}`$ is

```math
h_{k,\mathbf{x}}(u)=k\,g_{R,\mathbf{x}}(u)\,\bigl(1-H_{R,\mathbf{x}}(|u|)\bigr)^{k-1}. \tag{93}
```

Hence

```math
\displaystyle\mathbb{E}[S_{k}\mid\mathbf{x}] \displaystyle=k\int_{\mathbb{R}}u\,g_{R,\mathbf{x}}(u)\bigl(1-H_{R,\mathbf{x}}(|u|)\bigr)^{k-1}\,du \tag{94}
```

```math
\displaystyle=k\int_{0}^{\infty}u\bigl(g_{R,\mathbf{x}}(u)-g_{R,\mathbf{x}}(-u)\bigr)
```

```math
\displaystyle\bigl(1-H_{R,\mathbf{x}}(u)\bigr)^{k-1}\,du.
```

```math
\displaystyle\approx 2d_{R,\mathbf{x}}\,k\int_{0}^{\infty}u^{\beta+2}e^{-kA_{R,\mathbf{x}}u^{\beta+1}}\,du
```

```math
\displaystyle=\frac{2d_{R,\mathbf{x}}}{\beta+1}A_{R,\mathbf{x}}^{-\frac{\beta+3}{\beta+1}}\Gamma\!\left(\frac{\beta+3}{\beta+1}\right)k^{-\frac{2}{\beta+1}}.
```

Finally, writing

```math
\Delta_{x}:=\mu_{R}(\mathbf{x})-\mu_{T}(\mathbf{x}),
```

the generalization error in the mismatched case is

```math
\displaystyle\mathbb{E}\bigl[(Y_{(R)}-\mu_{T}(\mathbf{x}))^{2}\mid\mathbf{x}\bigr] \tag{95}
```

```math
\displaystyle=\Delta_{x}^{2}+2\Delta_{x}\,\mathbb{E}[S_{k}\mid\mathbf{x}]+\mathbb{E}[S_{k}^{2}\mid\mathbf{x}]
```

```math
\displaystyle=\Delta_{x}^{2}+4\frac{\Delta_{x}d_{R,\mathbf{x}}}{\beta+1}A_{R,\mathbf{x}}^{-\frac{\beta+3}{\beta+1}}\Gamma\!\left(\frac{\beta+3}{\beta+1}\right)k^{-\frac{2}{\beta+1}}
```

```math
\displaystyle+\frac{2}{\beta+1}A_{R,\mathbf{x}}^{-\frac{2}{\beta+1}}\Gamma\!\left(\frac{2}{\beta+1}\right)k^{-\frac{2}{\beta+1}}.
```

So when reward and target are misaligned, the error approaches the
nonzero floor $`\Delta_{x}^{2}`$, with the scaling exponent
$`2/(\beta+1)`$ controlling the first correction. The graph in Figure 9
can be fitted into $`\beta>0`$.

In particular, for settings in the main text $`\beta=0`$. Consequently,
at large $`k`$

```math
\displaystyle\delta(\mathbf{x})= \displaystyle\mathbb{E}\big[(Y_{(R)}-\mu_{T})^{2}\big] \tag{96}
```

```math
\displaystyle= \displaystyle(\mu_{R}(\mathbf{x})-\mu_{T}(\mathbf{x}))^{2}
```

```math
\displaystyle+(\mu_{R}(\mathbf{x})-\mu_{T}(\mathbf{x}))\frac{f_{x}^{\prime}\big(\mu_{R}(\mathbf{x})\big)}{f_{x}\big(\mu_{R}(\mathbf{x})\big)^{3}}\,\frac{1}{k^{2}}
```

```math
\displaystyle+\frac{1}{2k^{2}f_{x}\big(\mu_{R}(\mathbf{x})\big)^{2}}.
```

In particular, note that the second term could be positive or negative
depending on the level of reward misspecification. We have presented
numerical results for $`T=0`$ misspecified reward in Appendix H.1 after
averaging over $`\mathbf{x}`$. We see that these general theoretical
expectations are fulfilled.

##### Connection to tilted policy learning.

The large $`k`$ limit that we study here is connected to learning an
exponentially tilted policy relative to base generative model as we
explain next. The reward-reweighted exponentially tilted policy is
\[Aminian et al., 2025, Faria and Smith, 2025\]

```math
\displaystyle\pi_{T}(y\mid\mathbf{x},\mathcal{D})=\frac{e^{r(y,\mathbf{x})/T}\,p_{x}(y)}{Z_{T}(\mathbf{x})}, \tag{97}
```

```math
\displaystyle Z_{T}(\mathbf{x}):=\int e^{r(y^{\prime},\mathbf{x})/T}p_{x}(y^{\prime})dy^{\prime}.
```

Now consider the finite-sample procedure in our paper: given the sampled
set $`Y_{1:k}`$, this induces the empirical soft policy

```math
\displaystyle\widehat{\pi}_{k,T}(y\mid\mathbf{x},\mathcal{D};Y_{1:k}):=\sum_{i=1}^{k}\frac{e^{r(Y_{i},\mathbf{x})/T}}{\sum_{j=1}^{k}e^{r(Y_{j},\mathbf{x})/T}}\,\delta_{Y_{i}}(y). \tag{98}
```

Therefore, for any test function $`\varphi`$,

```math
\widehat{\pi}_{k,T}(\varphi)=\int\varphi(y)\,\widehat{\pi}_{k,T}(y)dy=\frac{\sum_{i=1}^{k}\varphi(Y_{i})e^{r(Y_{i},\mathbf{x})/T}}{\sum_{j=1}^{k}e^{r(Y_{j},\mathbf{x})/T}}.
```

As $`k\to\infty`$, $`\widehat{\pi}_{k,T}(\varphi)\to\pi_{T}(\varphi)`$.
If $`\mathbb{E}`$ denotes expectation over the inference-time samples
$`Y_{1:k}`$, the generalization error is given by,
$`\delta(\mathbf{x})=\mathbb{E}(\widehat{\pi}_{k,T}(\ell))`$ with
$`\ell(y):=(y-\mu_{T}(\mathbf{x}))^{2}`$. So the finite-$`k`$ rule
studied in our paper is a finite sampled approximation to the
reward-reweighted exponentially tilted policy, and our theorem computes
the leading corrections to generalization error in a closed form under
this policy.

_(i) A reward–loss coupling coefficient controlling expected finite
sample policy difference._

A natural measure of how strongly reward and task are coupled under the
base predictive law $`p_{x}`$ is

```math
\mathcal{A}(\mathbf{x}):=-\mathrm{Cov}_{\mathbf{x}}(\ell,r).
```

Indeed, the large-$`T`$ expansion discussed previously gives

```math
\displaystyle\mathbb{E}(\widehat{\pi}_{k,T}(\ell))-\pi_{T}(\ell)=\frac{1}{kT}\,\mathcal{A}(\mathbf{x})+O(T^{-2}). \tag{99}
```

So the leading gain from reranking is controlled exactly by this
covariance-type coupling parameter.

_(ii) A decoupling coefficient controlling random finite sample policy
difference._

If instead one wants the quantity
$`\widehat{\pi}_{k,T}(\ell)-\pi_{T}(\ell)`$ that measures how hard it is
for a finite sample budget $`k`$ to realize the ideal tilted policy
$`\pi_{T}`$, the natural continuous object is the second moment of the
importance weights:

```math
\displaystyle C(\mathbf{x}):=\frac{\mathbb{E}_{Y\sim p_{x}}\bigl[(e^{r(Y,\mathbf{x})/T})^{2}\bigr]}{\Bigl(\mathbb{E}_{Y\sim p_{x}}\bigl[e^{r(Y,\mathbf{x})/T}\bigr]\Bigr)^{2}}. \tag{100}
```

If the weights are well spread out, then the estimator behaves like an
average of roughly $`k`$ useful samples, and therefore its error has the
usual scale $`k^{-1/2}`$. By contrast, if the weights are highly uneven,
then only a small number of samples contribute appreciably to the
normalized average, and the estimator becomes correspondingly harder.
The quantity $`C(\mathbf{x})`$ measures exactly this weight
concentration. It equals $`1`$ when the weights are constant, and
becomes larger when the tilted distribution is harder to approximate
using samples drawn from the base distribution $`p_{x}`$. For more
related discussion see \[Aminian et al., 2025\].

## Appendix G Going beyond independent inference time sampling: self-consistency and beam search

In this appendix we briefly sketch two speculative extensions of the
inference-time sampling-and-selection framework studied in the main
text. Both ideas introduce dependence between candidates, going beyond
the i.i.d. sampling assumption that enables the clean proportional-limit
analysis in this paper. While we do not pursue these directions here,
they appear promising and may admit tractable approximations closely
related to the calculations already developed.

### G.1 Self-consistency

A common heuristic in LLM decoding is to prefer answers that are not
only high-reward individually, but also supported by other sampled
candidates. This idea is often referred to as self-consistency:
candidates that agree with many others are treated as more reliable. We
can model this by augmenting the selection score with a consensus
kernel:

```math
s_{i}\;=\;\sum_{j\neq i}K_{\tau}(y_{i},y_{j}),\qquad K_{\tau}(y,y^{\prime})\;=\;\exp\!\Big(-\frac{(y-y^{\prime})^{2}}{\tau}\Big),
```

and scoring each candidate with

```math
\underbrace{r(y_{i},\mathbf{x})}_{\text{alignment to reward}}\;+\;\beta\underbrace{\log s_{i}}_{\text{alignment to consensus}},
```

for some $`\beta\geq 0`$. The softmax then uses
$`\exp\!\big([\,r_{R}(y_{i},\mathbf{x})+\beta\log s_{i}\,]/T\big)`$. For
the purpose of analytical calculations it is reasonable to approximate
$`s_{i}\to\mathbb{E}[s_{i}\mid y_{i}]`$ in this expression. This in
effect rescales $`T`$ and shifts $`\mathbf{w}_{R}`$. The theoretical
analysis can be performed following similar steps as in the paper.

### G.2 Beam search

Another practically important decoding primitive is beam search, which
introduces a structured pruning step before selection. We model a
simplified, one-step abstraction of this mechanism as follows. Fix a
search budget $`K`$ (total proposals explored by the decoder) and a beam
width $`B\in\{1,\dots,K\}`$ (candidates kept after pruning). A beam
search operator $`\mathcal{B}_{K,B}`$ keeps the $`B`$ proposals:

```math
\displaystyle\{Y_{(1)},\dots,Y_{(B)}\} \displaystyle=\;\mathcal{B}_{K,B}\big(\{Y_{i}\}_{i=1}^{K}\big) \tag{101}
```

```math
\displaystyle=\;\arg\mathrm{top}\text{-}B\;\{-|Y_{i}-m|\}_{i=1}^{K}.
```

These $`B`$ kept candidates are then passed to our reward-weighted
selector (softmax over $`r(y,\mathbf{x})`$ at temperature $`T`$).

The marginal distribution of a kept value under $`\mathcal{B}_{K,B}`$ is
well-approximated by (we take correlations into account later):

```math
q_{\mathrm{beam}}(y\mid\mathbf{x},\mathcal{D})\;\propto\;\mathcal{N}(y\mid m,s^{2})\,\mathbf{1}\!\left\{|y-m|\leq t_{B}\right\},
```

where the truncation threshold $`t_{B}`$ is chosen so that the expected
keep rate matches $`B/K`$:

```math
\Pr\!\big(|Y-m|\leq t_{B}\big)\;=\;\frac{B}{K}
```

Under symmetric truncation, the mean remains $`m`$ and the variance
$`s^{2}`$ contracts to $`s_{\mathrm{beam}}^{2}`$.

Even if $`Y_{1},\dots,Y_{K}`$ are i.i.d., the kept vector
$`\big(Y_{(1)},\dots,Y_{(B)}\big)`$ is not independent (order-statistic
coupling). A standard correction is to replace $`k`$ by an effective
size $`k_{\mathrm{eff}}`$ such that
$`Var(\bar{g}_{B})=Var(g(Y_{(i)})/k_{\mathrm{eff}}`$,
$`\bar{g}_{B}=\tfrac{1}{B}\sum_{i=1}^{B}g(Y_{(i)})`$. Simplest case
would correspond to choosing $`g(x)=x`$.

In summary, we expect that the replacements
$`s^{2}\to s_{\mathrm{beam}}^{2},k\to k_{\mathrm{eff}}`$ in our formula
would capture the effect of beam search.

### H.2 Large language model

Here we present experimental details for LLM based evaluations presented
in the main text along with additional results.

#### H.2.1 Task, prompting, and generation protocol

We evaluate inference-time scaling on GSM8K validation dataset using the
lm-evaluation-harness task gsm8k_cot_self_consistency. Our prompt format
is chain-of-thought few-shot prompting with 8 CoT exemplars (8-shot CoT)
For each test question, the base model is asked to produce a full
reasoning trace followed by a final answer in the format “The answer is
{number}”. We sample stochastically at generation temperature $`0.2`$.
and extract the final numeric answer using a regular expression matching
“The answer is (number)”. We also log all reasoning steps to enable
Judge-LLM-based selection.

#### H.2.2 Base models and judge models

##### Base LLMs.

We run inference experiments with a diverse set of base large language
models: Qwen3-8B, Llama-3-8B-Instruct, Mistral-7B-Instruct-v0.3,
deepseek-math-7b-rl, gemma-3-4b-it, and DeepSeek-R1-Distill-Qwen-1.5B.
Inference is executed via the vLLM backend through lm_eval with
model-specific --model_args, e.g. tensor/data-parallel settings.

##### Judge LLMs.

We score each sampled CoT using two types of judge models: process
reward model Qwen2.5-Math-PRM-7B and casual LLM
Mistral-7B-Instruct-v0.3. For the causal judge, we prompt the judge to
output a scalar score in $`[0,10]`$. We use a short/weak prompt and a
detailed/strong prompt. Examples of each of these prompts are given
below. For the PRM, we convert the sampled reasoning into a
chat-formatted transcript and insert a step separator token \<extra_0\>
after each reasoning step; the PRM score is computed from the model’s
per-token probability that each separator is classified as “positive”
and then scaled to $`[0,10]`$. For judges we use deterministic sampling.
PRM based judge is known to be much stronger judge compared to the
causal model based judge. Our experimental results reflect this - for
instance Llama model’s accuracy increased from $`77\%`$ to $`87\%`$
under PRM judge, whereas under causal judge it went up only by $`1\%`$.
